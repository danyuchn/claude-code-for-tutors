# 單元六 學習單（草稿）

## 主題：食物與飲食習慣（Food and Eating Habits）

### 一、暖身：你今天吃了什麼？
用英文寫出你今天三餐吃的東西，至少各兩樣。

### 二、單字配對
把左邊的英文和右邊的中文連起來。

breakfast / lunch / dinner / snack / vegetable / fruit / meat / rice

### 三、句型練習
用 "I usually have ___ for breakfast." 造三個句子。

### 四、閱讀短文
（此處需要一張圖：一家人圍著餐桌吃早餐的場景，讓學生描述看到什麼）

### 五、小組活動
兩人一組，訪問對方的飲食習慣，記錄下來。
