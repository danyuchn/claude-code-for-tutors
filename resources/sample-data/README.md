# 範例資料說明

本目錄包含課程練習用的虛擬資料集，所有資料皆為虛構，不包含真實個人資訊。

## 資料檔案

### student-roster.csv — 學生名單
**位置**：`.claude/horizon-academy/sample-data/student-roster.csv`
**用途**：課程 2-3（建立學生資料庫）、課程 3-3（學生進度查詢）
**欄位**：
- 學號、姓名、年級、組別、家長姓名、家長電話、緊急聯絡信箱、備注

### exam-scores.csv — 月考成績
**位置**：`.claude/horizon-academy/sample-data/exam-scores.csv`
**用途**：課程 2-1（個人化家長回覆）、課程 3-1（成績分析）、課程 3-3（進度查詢）
**欄位**：
- 學號、姓名、第一次月考、第二次月考、第三次月考、出席率(%)、作業繳交率(%)

### parent-survey.csv — 家長滿意度調查
**位置**：`.claude/horizon-academy/sample-data/parent-survey.csv`
**用途**：課程 3-2（問卷分析）
**欄位**：
- 填寫日期、孩子姓名、整體滿意度(1-5)、教學品質(1-5)、溝通效率(1-5)、建議與意見

## 使用注意事項

1. **隱私**：這些資料是虛構的，練習時請不要把真實學生個資替換進來
2. **位置**：課程中引用的路徑為 `.claude/horizon-academy/sample-data/`，使用前請確認 Claude Code 在正確的工作目錄
3. **自訂**：歡迎根據你的實際課程情境修改這些範例資料

## 建立你自己的資料

學會課程後，你可以建立符合你學校情境的資料集：

```bash
# 在你的工作目錄建立資料資料夾
mkdir ~/[你的學校名稱]/data

# 讓 Claude 幫你生成虛擬資料測試
# 「請幫我生成一份 25 位學生的虛擬名單 CSV，欄位包含：學號、姓名、年級、電話」
```
