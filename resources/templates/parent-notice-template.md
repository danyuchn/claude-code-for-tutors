# 家長通知信模板

## 使用說明

在 Claude Code 中使用時，請貼入此模板並填入 `[方括號]` 中的內容，或直接告訴 Claude：
「請用家長通知信模板幫我寫一封關於 [事件] 的信」

---

## 模板 1：緊急通知（需要立即行動）

```
[家長姓名] 您好，

關於 [學生姓名] 的 [事件類型]，需要盡快與您溝通。

【情況說明】
[具體描述發生的事]

【需要您配合的行動】
- [行動項目 1]
- [行動項目 2]

【聯絡方式】
請於 [截止時間] 前聯絡我：
- LINE：[帳號]
- 電話：[電話]

謝謝您的配合。

[老師姓名]
[日期]
```

---

## 模板 2：一般通知（課程、活動、調課等）

```
[家長姓名] 您好，

想跟您說明關於 [主題] 的安排。

【主要內容】
[2-3 句話說明]

【重要時間/日期】
- [日期事項 1]
- [日期事項 2]

【注意事項】
[如有特殊需要準備的事項]

如有任何問題，歡迎隨時聯絡我！

[老師姓名]
[日期]
```

---

## 模板 3：好消息分享（進步、表揚、成就）

```
[家長姓名] 您好，

想和您分享一個好消息！[學生姓名] 最近 [具體成就/進步]。

[2-3 句描述具體表現，要有細節]

這樣的進步需要孩子的努力，也需要家長在家的支持。謝謝您！

繼續加油！

[老師姓名]
[日期]
```

---

## Claude 使用小技巧

貼入模板後，可以對 Claude 說：
- 「請幫我填入這封信的內容，背景是：[說明情況]」
- 「把這封信的語氣改得更溫暖一點」
- 「幫我用這個模板，生成全班 20 封個人化通知信」
