## 題型配置

### 初級（30 分）——選擇題

**出題方向**：考核基本概念理解，4 選 1
**範例格式**：
```
1. （  ）以下哪個句子的現在完成式使用正確？
   (A) I have saw that movie.
   (B) She has visited Paris three times.
   (C) They have went to school yesterday.
   (D) He has born in 1990.
   答案：B
   解析：現在完成式用於描述...
```

---

### 中級（40 分）——填空題

**出題方向**：考核活用能力，填入正確形態
**範例格式**：
```
2. Mary ________ (study) English for five years.
   （填入正確的動詞形態）
   答案：has studied
   解析：since/for 搭配現在完成式，表示...
```

---

### 高級（30 分）——閱讀理解

**出題方向**：短文理解 + 應用
**範例格式**：
```
【短文】（80-100 字）
[英文短文]

3. According to the passage, ...
   答案：
   解析：
```

## Claude 出題指令範例

```
請幫我出一份英文考試，條件如下：
- 主題：[現在完成式]
- 年級：[國中三年級]
- 題型：按照模板的初級（選擇題 5 題）、中級（填空 5 題）、高級（閱讀 1 篇 + 3 題）
- 每題附詳細解析
- 情境要貼近台灣中學生的生活
```

## 出題品質檢查清單

完成後讓 Claude 做品質確認：
- [ ] 難度是否符合年級程度？
- [ ] 題目情境是否合適？
- [ ] 答案是否正確？
- [ ] 解析是否清楚易懂？
- [ ] 有沒有重複上次考過的內容？
