# 真實教師使用案例

這裡收集使用本課程的真實教師的使用心得和案例分享。

## 為什麼要分享案例？

- **幫助其他老師**：真實的使用場景比示範更有說服力
- **建立社群**：讓使用 AI 的老師互相學習和鼓勵
- **改善課程**：你的回饋幫助我們讓課程更好

## 分享格式

請在你的案例文件中包含以下內容（約 300-500 字）：

```markdown
# 案例：[一句話標題]

**作者**：[你的名字或匿名代號]
**學校類型**：[補習班/公立國中/私立高中/...]
**科目**：[你教的科目]
**完成課程時間**：[約幾週]

## 我遇到的問題

[上課程之前，你的哪個工作讓你最困擾？]

## 我怎麼用 Claude Code 解決

[描述你用了課程中哪個技能，以及如何應用到你的真實情境]

## 實際效果

[量化的改變：例如「每週節省 X 小時」「家長滿意度從 X 提升到 Y」]

## 遇到的挑戰和解決方式

[過程中有什麼困難？怎麼克服的？]

## 給其他老師的建議

[一句話給還在猶豫的老師]
```

## 如何提交

1. Fork 此倉庫
2. 在 `community/case-studies/` 建立你的案例文件
   - 命名：`case-[年份]-[月份]-[你的代號].md`
   - 例：`case-2026-03-teacher-lin.md`
3. 提交 Pull Request
