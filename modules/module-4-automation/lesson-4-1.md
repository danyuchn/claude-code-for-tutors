# 課程 4-1：設計你的第一個教學 Workflow

把每月重複的月報告流程，變成一個可以一鍵執行的自訂指令——而且 AI 會在規劃階段就主動發現限制。

## 課程來源
改編自：`module-03-automation-06.md`（`claude-course/lessons/module-03-real-world/`）
原始場景：使用者想打造每日 AI 新聞 Podcast 自動化工作流，Claude 先理解現況、搜尋資訊，使用者中途改方向（「不能用 tikhub 嗎？」），Claude 立刻調整；規劃階段主動發現 Google Podcast API 限制並詢問使用者
核心 AI 行為：複雜口語需求 → 先理解現況 → 使用者中途改方向 → 發現 API 限制 → 主動提問
驚喜時刻：小艾主動說「Google Classroom API 需要管理員權限，你有嗎？」——不是等到執行失敗才說，而是事先發現限制

## 課程資訊
- **適合對象**：完成 Module 3 的學員
- **所需時間**：20 分鐘
- **學習重點**：
  - 理解「自訂指令（Custom Command）」的概念——把多步驟流程寫成可一鍵執行的指令
  - AI 會在規劃階段就主動發現技術限制，而不是等到失敗才說
  - 使用者中途調整需求時，AI 會立刻改變方向
  - 把反覆執行的工作流程自動化，節省每月重複的時間
- **工具需求**：Claude Code，`~/horizon-academy/` 資料夾
- **本課產出**：`/monthly-report` 自訂指令（`.claude/commands/monthly-report.md`）

## 拍攝腳本

### 場景 1：開場情境（30 秒）

**畫面：**
林老師坐在辦公桌前，面前堆著月考成績單 Excel、出席率統計表、上個月的月報 Word 文件。她嘆了口氣，打開 Claude Code。

**旁白：**
「每個月底，林老師都要做同樣的事：從 Google Classroom 匯出成績、統計出席率、找出需要關注的學生、寫月報給家長。每次花兩個小時，而且每次都從頭來過。今天她想試試，能不能讓 AI 幫她把這整套流程變成一個按鈕。」

**字幕：**
```
今天的任務：把月報流程變成一鍵指令
林老師的煩惱：每個月花 2 小時做一樣的事
```

---

### 場景 2：口語描述需求——AI 先理解現況（60 秒）

**畫面：**
林老師打字輸入，Claude 開始回應並提問

**使用者輸入：**
```
我每個月都要做月報給家長，超花時間的，
要收集成績、整理、然後一封一封發，能不能幫我做成自動的？
```

**Claude 回應：**
```
好，我先了解一下你現在的流程：
- 成績在哪裡？（Google Classroom？手動 Excel？）
- 月報現在是什麼格式？（PDF？Google Docs？Word？）
- 發給家長的方式？（Email？LINE？紙本？）
```

**旁白：**
「注意看，林老師只是模糊地說『做月報給家長，超花時間的』。AI 沒有直接開始寫程式，而是先問了三個關鍵問題——成績來源、月報格式、發送方式。這就像一個有經驗的同事，接到新任務時會先釐清需求，而不是埋頭就做。」

**字幕：**
```
關鍵學習點：AI 會先理解現況再行動
林老師說的：「幫我做成自動的」
AI 做的：先問三個關鍵問題，釐清流程
```

---

### 場景 3：驚喜時刻——AI 主動發現限制（60 秒）

**畫面：**
林老師回覆後，Claude 規劃流程時主動提出一個限制

**使用者輸入：**
```
Classroom 的，Word 格式，LINE 群發
```

**Claude 回應：**
```
了解了。我來設計一個三步驟的月報工作流：
1. 自動從 Google Classroom 抓成績
2. 生成個人化月報（每位學生不同）
3. 批次發送到家長 LINE

不過有個問題——Google Classroom API 需要管理員權限才能讀取成績。
你有明日學院系統的管理員帳號嗎？還是只有老師帳號？
```

**旁白：**
「這裡是今天的驚喜時刻！AI 在規劃階段就主動發現了一個技術限制：Google Classroom API 需要管理員權限。它不是等到程式寫完、執行失敗了才跟你說『抱歉，權限不夠』——而是在動手之前就先告訴你。這種『預見問題』的能力，省下的不只是時間，更是避免了白忙一場的挫折感。」

**字幕：**
```
驚喜時刻：AI 主動預見技術限制
不是等到失敗才說，而是規劃時就發現
「Google Classroom API 需要管理員權限，你有嗎？」
```

### 場景 4：中途調整方向——AI 立刻適應（50 秒）

**畫面：**
林老師回覆她只有老師帳號，Claude 立刻改變方案

**使用者輸入：**
```
只有老師帳號
```

**Claude 回應：**
```
沒問題，我改用另一個方案：
你每個月從 Classroom 把成績匯出成 CSV 檔案（30 秒就能做好），
我來自動化後面的所有步驟：

1. 讀取你匯出的 CSV 成績檔
2. 計算全班平均、各組表現、進退步名單
3. 找出需要關注的學生（出席率 < 80% 或成績下滑 > 10 分）
4. 生成每位學生的個人化月報
5. 準備 LINE 發送清單（家長姓名 + 訊息內容）

這些步驟我可以幫你寫成一個自訂指令，
以後每個月只要匯出 CSV，輸入 /monthly-report 就全部自動跑完。

要不要我現在就幫你建立這個指令？
```

**旁白：**
「林老師說『只有老師帳號』，AI 馬上調整方案——從全自動抓取，改成『你匯出 CSV，剩下的我自動化』。它完全沒有堅持原本的計畫，也沒有抱怨，而是立刻找到替代方案。而且注意，調整後的方案更實用：只多了一個 30 秒的手動步驟，後面全部自動化。」

**字幕：**
```
關鍵學習點：AI 會根據限制調整方案
原方案：全自動抓取（需管理員權限）
調整後：手動匯出 CSV + 全自動分析報告
結果：更務實、更容易執行
```

好，我來建立指令檔案：

請按照以下步驟生成本月班級報告：

1. 讀取 ~/horizon-academy/sample-data/exam-scores.csv

**旁白：**
「AI 幫林老師建立了一個自訂指令檔案。這個檔案就像一份 SOP 手冊，寫清楚每個步驟該做什麼。以後只要輸入 `/monthly-report`，Claude 就會照著這份 SOP 自動執行所有步驟。一次設定，每個月都省兩小時。」

**字幕：**
```
自訂指令 = 你的 AI SOP 手冊
寫一次，每個月自動執行
位置：.claude/commands/monthly-report.md
```

## 常見問題

### Q：自訂指令的檔案放在哪裡？
A：放在 `.claude/commands/` 資料夾裡，檔名就是指令名稱。例如 `monthly-report.md` 對應指令 `/monthly-report`。

### Q：指令內容寫得越詳細越好嗎？
A：關鍵步驟要寫清楚，但不需要寫到每個技術細節。想像你在交代工作給一位聰明的實習生——告訴它「要做什麼」和「品質標準」就好。

### Q：如果 AI 規劃時發現了我不懂的技術限制怎麼辦？
A：直接問它「有沒有替代方案？」就像今天的場景一樣，AI 會立刻幫你想辦法。不懂技術完全沒關係，AI 會用你聽得懂的方式解釋。
