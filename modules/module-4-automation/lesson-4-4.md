# 課程 4-4：你的專屬教學 AI 助理（畢業專案）

為自己打造真正個人化的 AI 助理——讓 Claude 了解你是誰、怎麼工作。

## 📋 課程資訊
- **適合對象**：完成整個課程的學員（畢業專案！）
- **所需時間**：25 分鐘
- **學習重點**：
  - 學會撰寫個人化的 CLAUDE.md（讓 AI 了解你）
  - 建立 3 個最常用的個人自訂指令
  - 整合課程所有技能打造完整的 AI 工作系統
- **工具需求**：Claude Code
- **本課產出**：
  - 個人化 `~/horizon-academy/CLAUDE.md`
  - 3 個自訂指令：`/批改建議`、`/家長信`、`/課程規劃`
- **教師獨有場景**：✅ 是

## 🎬 拍攝腳本（骨架）

### 場景 1：畢業典禮開場（20 秒）
> 林老師回顧這段課程的旅程
> 從對 AI 感到焦慮，到現在有自己的工作流程

### 場景 2：Part 1——撰寫個人 CLAUDE.md（60 秒）
> 引導林老師回答 5 個關鍵問題
> Claude 幫她整理成完整的個人 CLAUDE.md

**關鍵指令範例：**
```
請幫我建立個人化的 CLAUDE.md，以下是我的工作情境：

【我是誰】
- 林欣怡，明日學院英文老師，8 年教齡
- 同時擔任課程協調組長

【我最常需要 AI 幫忙的工作】
1. 生成個人化的家長通知信（每週約 20 封）
2. 分析班級成績找出需要關注的學生
3. 規劃課程大綱和教學材料

【我的溝通偏好】
- 語氣：溫暖、親切，不要太正式
- 輸出格式：直接可用的文字，不要加太多說明
- 回應長度：簡潔，除非我要求詳細說明

【我的學生背景】
- 國中到高中，年齡 12-18 歲
- 英文程度：初中級到中高級
- 學習目標：升學考試 + 實用英文溝通

【重要限制】
- 學生個資只在本機處理，不上傳雲端
- 所有中文輸出使用繁體中文

請整理成一份清楚的 CLAUDE.md，儲存到 ~/horizon-academy/CLAUDE.md
```

### 場景 3：Part 2——建立 3 個自訂指令（60 秒）
> 為三個最常用的任務各建立一個指令

**指令 1：/批改建議**
```
幫我建立 /批改建議 指令：
當我貼入學生作文時，請：
1. 指出 3 個最需要改進的地方（語法/詞彙/結構）
2. 每個問題給一個具體的改善建議
3. 給一個整體評語（50 字以內，語氣鼓勵）
注意：只給建議方向，不要直接改文章
```

**指令 2：/家長信**
```
幫我建立 /家長信 指令：
當我說明情況（好消息/一般通知/需要改善），請：
1. 生成一封溫暖但專業的家長通知信
2. 語氣符合林欣怡老師的個人風格
3. 結尾有明確的行動步驟（如需要）
```

**指令 3：/課程規劃**
```
幫我建立 /課程規劃 指令：
當我說明課程目標和限制，請：
1. 整理出有週次的課程大綱
2. 每週包含：主題、活動、評量
3. 輸出為可直接使用的表格格式
```

### 場景 4：測試你的個人 AI 助理（30 秒）
> 用一個真實的工作情境測試
> 比較「使用 CLAUDE.md 前後」的回應差異

### 場景 5：畢業典禮——給林老師的話（25 秒）
> 回顧所學，鼓勵繼續探索
> AI 是讓老師把時間花在更有意義的事上的工具

## 📖 常見問題

### Q：建立好的 CLAUDE.md，以後每次都要搬過來嗎？
A：有兩種方式：(1) 把通用設定放在全域的 `~/.claude/CLAUDE.md`，(2) 把工作專用設定放在專案資料夾。可以兩個都用！

### Q：完成課程後，還有哪裡可以繼續學習？
A：查看 `community/case-studies/` 裡的真實使用案例，或貢獻你自己的故事！
