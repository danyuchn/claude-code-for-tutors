# 課程 4-2：批量處理：一次搞定 200 份教材

讓 AI 幫你統一命名 200 份教材檔案——而且它還會額外發現你沒注意到的問題。

## 課程資訊
- **適合對象**：完成課程 4-1 的學員
- **所需時間**：18 分鐘
- **學習重點**：
  - AI 可以一次處理大量檔案，不會漏掉、不會累
  - AI 會主動發現超出任務範圍的問題（重複檔案、損壞檔案）
  - 批量操作的安全原則：先預覽、再確認、最後執行
  - 「先看再做」的安全操作流程
- **工具需求**：Claude Code，`~/horizon-academy/` 資料夾
- **本課產出**：200 份教材檔案統一命名完成 + 問題檔案報告

**畫面：**
林老師輸入需求，Claude 開始掃描檔案

```

**Claude 回應：**
```
好，我先看看所有檔案的情況...

掃描完成，共找到 203 份檔案。

**旁白：**
「林老師只說了『幫我統一命名』這五個字，AI 就自動掃描了全部 200 多份檔案，還分析出目前的命名狀況。更重要的是，它在動手之前先問了一句：『要我先列出計畫讓你確認嗎？』這就是批量操作的安全原則——先預覽再執行。」

**字幕：**
```
關鍵學習點：批量操作前先預覽
AI 做的：掃描全部 → 分析現況 → 建議規則 → 等你確認
```

## 延伸練習

### 練習 1：安全測試
在 `~/horizon-academy/test-rename/` 建立 10 個命名混亂的測試檔案，練習「預覽 → 確認 → 執行」的完整流程。

### 練習 2：不同命名規則
設計適合你學校的命名規則。例如：「學年度-學期-年級-科目-類型」，然後讓 AI 幫你批量執行。

### 練習 3：找出重複檔案
請 AI 掃描你的教材資料夾，專門找出內容相似或重複的檔案，整理成清單讓你決定要保留哪些。

## 常見問題

### Q：批量操作會不會改錯檔案？
A：只要遵守「先預覽再執行」的原則，就不會。AI 會先列出完整計畫讓你確認，你說「執行」才會真的改。如果不放心，可以先在測試資料夾練習。

### Q：如果 AI 重命名的規則我不滿意怎麼辦？
A：直接跟它說你想要的規則就好。例如：「年級放前面」、「不要序號」、「用底線不要用橫線」。AI 會按照你的偏好調整。

### Q：真的需要先建測試資料夾嗎？
A：強烈建議。批量操作一旦執行就很難復原，特別是重命名後你可能記不住原本的檔名。在測試資料夾練習一次，確認規則沒問題再處理真正的檔案。
