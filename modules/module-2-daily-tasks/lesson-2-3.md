# 課程 2-3：建立與更新學生資料庫

用自然語言操作學生資料庫——搜尋、新增、更新，AI 會自己修正搜尋方向。

## 課程資訊
- **適合對象**：完成課程 2-2 的學員
- **所需時間**：15 分鐘
- **學習重點**：
  - 了解 Claude 可以讀取和修改 CSV 格式資料
  - 學會用口語化指令搜尋、新增、更新學生資料
  - 體驗 AI 的「自我修正」能力——找錯資料時會主動說明並繼續搜尋
- **工具需求**：Claude Code，`student-roster.csv`
- **本課產出**：更新後的學生資料庫（含新生資料和備注欄位）
- **教師獨有場景**：否（通用技能）

---

## 拍攝腳本

### 場景 1：新學期困境（25 秒）

**畫面：**
林老師的桌上散落著各種新生資料——LINE 訊息截圖、Google 表單列印、手寫的家長聯絡卡。

**旁白：**
「新學期開始，10 位新生的資料從四面八方湧來。有人 LINE 傳、有人填表單、有人還是手寫。要手動一筆一筆整理到 Excel 裡，光想就頭痛。今天我們讓 Claude 來當資料整理助理。」

**字幕：**
新學期新生資料：LINE 訊息、Google 表單、手寫卡片
一筆一筆打？太累了！

### 場景 2：讓 Claude 讀取現有名單（30 秒）

**畫面：**
打開 Claude Code，輸入指令讓 Claude 讀取 student-roster.csv。

**旁白：**
「第一步，讓 Claude 看看現有的學生名單長什麼樣子。它會自動理解欄位結構和學號規則。」

**使用者輸入：**
```
幫我看一下 student-roster.csv，告訴我裡面有哪些欄位、最後一個學號是什麼
```

**Claude 回應：**
```
[Tool: Read] student-roster.csv

名單中有 89 位學生，欄位包含：
- 學號（S001-S089）
- 姓名、年級、班級
- 家長姓名、聯絡電話
- 備注

最後一個學號是 S089。
```

### 場景 3：貼入新生資料（45 秒）

**畫面：**
林老師直接把各種格式的新生資料貼給 Claude。

**旁白：**
「現在把那些亂七八糟的新生資料，直接原封不動地貼給 Claude。不用自己先整理格式，讓 AI 來處理。」

**使用者輸入：**
```
請幫我把以下新生資料加入 student-roster.csv：

1. 陳小明，國三，家長：陳志明，電話：0912-345-678
2. 林雨晴，高一，需要全英授課
   家長：林淑華，電話：0923-456-789
3. 黃大偉，國一，家長：黃建國，電話：0934-567-890

學號按照現有規則接著排，缺少的欄位標「待補」
```

**Claude 回應：**
```
[Tool: Edit] student-roster.csv

已新增 3 位學生：
- S090 陳小明（國三）
- S091 林雨晴（高一）- 備注：需要全英授課
- S092 黃大偉（國一）

缺少的欄位（如班級）已標記「待補」。
目前共有 92 位學生。
```

### 場景 4：模糊搜尋的驚喜時刻（50 秒）

**畫面：**
陳老師走過來請林老師幫忙查一位學生的資料。

**旁白：**
「這時候陳老師跑過來問：『欸林老師，幫我找一下陳建宏同學的資料。』我們直接問 Claude。注意接下來發生的事。」

**使用者輸入：**
```
幫我找一下陳建宏同學的資料
```

**Claude 回應：**
```
[Tool: Read] student-roster.csv

我搜尋了「陳建宏」，找到一位姓名相近的學生：
陳柔安（S089），但這不是你要找的「陳建宏」。

讓我擴大搜尋範圍...

[Tool: Grep] 搜尋更多資料來源

找到了！陳建宏在高中部名單（S112），不在你的班級 student-roster.csv 裡。
他在數學組，你要的是他的英文輔導需求嗎？
```

**旁白：**
「看到了嗎？這就是今天最重要的一課。Claude 找到了『陳柔安』，但它知道這不是我們要的『陳建宏』。它沒有就這樣回報說找到了，而是主動說『這不是你要找的人，讓我繼續找』。AI 自己知道自己找錯了，不需要老師提醒。」

**字幕：**
驚喜時刻：AI 自我修正！
找到「陳柔安」但知道不對 → 主動繼續搜尋 → 找到正確的「陳建宏」

### 場景 5：更新學生備注（30 秒）

**畫面：**
林老師想在學生資料裡加一些教學備注。

**旁白：**
「找到學生之後，我們可以直接用口語化的方式更新資料。」

**使用者輸入：**
```
幫我在 S091 林雨晴的備注加上「英文程度中上，適合進階閱讀素材」，
然後把 S090 陳小明的班級從待補改成 303
```

**Claude 回應：**
```
[Tool: Edit] student-roster.csv

已更新：
- S091 林雨晴：備注更新為「需要全英授課；英文程度中上，適合進階閱讀素材」
- S090 陳小明：班級從「待補」改為「303」
```

### 場景 6：驗證和總結（25 秒）

**畫面：**
請 Claude 做最終確認。

**使用者輸入：**
```
幫我確認一下：現在共有幾位學生？有哪些資料還是「待補」的？
```

**Claude 回應：**
```
目前共 92 位學生。

以下欄位仍標記「待補」：
- S092 黃大偉：班級待補
- S091 林雨晴：家長電話格式需確認（有多一個空格）

建議：開學後補齊這些資料。
```

**旁白：**
「Claude 不只告訴我們哪些是待補的，還主動發現林雨晴的電話格式有問題。用自然語言就能操作整個學生資料庫——搜尋、新增、更新、驗證，全部搞定。」

### 場景 7：收尾（20 秒）

**旁白：**
「今天最大的收穫是什麼？不只是學會了用 Claude 管理資料，更重要的是看到了 AI 的自我修正能力。當它找到的結果不對時，它會主動告訴你、然後繼續找。這代表你不用隨時盯著它，它會對自己的工作品質負責。」

## 延伸練習

### 練習 1：格式轉換
把一份不同欄位格式的學生清單（例如從其他學校轉來的），轉換成你學校的標準格式。

### 練習 2：資料驗證
讓 Claude 檢查名單中的資料品質：重複學號、缺少必填欄位、電話格式不一致等問題。

### 練習 3：條件篩選
請 Claude 篩選出特定條件的學生，例如「列出所有需要特殊安排的學生」或「找出國三年級、沒有填家長電話的學生」。

- [ ] 用口語化指令搜尋、更新學生資料
- [ ] 理解 AI 的自我修正行為——找錯時會主動告知並繼續搜尋
