# 課程 2-4：出作業、出考題不再傷腦筋

AI 不只幫你出題，還會先分析學生的錯誤模式，針對認知盲點出題。

## 課程資訊
- **適合對象**：完成課程 2-3 的學員
- **所需時間**：15 分鐘
- **學習重點**：
  - 學會讓 AI 先分析錯誤模式，再針對盲點出題
  - 理解「AI 出題、老師審題」的最佳工作流程
  - 掌握如何指定難度、題型、考點
- **工具需求**：Claude Code，`exam-scores.csv`
- **本課產出**：三難度題組各 5 題（含答案和詳細解析）
- **教師獨有場景**：是

## 拍攝腳本

### 場景 1：出題的痛（25 秒）

**畫面：**
林老師對著電腦螢幕苦思，旁邊是一疊教材和筆記。

**旁白：**
「出題是老師最耗時的工作之一。花了兩個小時精心設計的考卷，學生 15 分鐘就寫完。更讓人沮喪的是，出完題才發現根本沒有考到學生真正不會的地方。今天我們要讓 AI 先幫你找到學生的盲點，再針對盲點出題。」

**字幕：**
花 2 小時出題 → 學生 15 分鐘寫完
更慘的是：沒考到真正不會的地方

### 場景 2：先分析再出題（45 秒）

**畫面：**
林老師輸入指令，請 Claude 分析上次考試的成績資料。

**旁白：**
「一般的做法是『出 10 題時態練習題』。但今天我們換個方式：先讓 Claude 看看學生到底哪裡不會。」

**使用者輸入：**
```
這次月考動詞時態題大家都考得很差，幫我出 10 題練習題
```

### 場景 3：AI 深挖盲點的驚喜時刻（60 秒）

**畫面：**
Claude 沒有直接出題，而是先分析了錯誤分布。

**旁白：**
「注意，Claude 沒有馬上出題。它先說了一句『等一下，我先看看錯誤集中在哪裡』。這就是今天最重要的時刻。」

**Claude 回應：**
```
等一下，我先看看錯誤的分布。

[Tool: Read] exam-scores.csv（分析各題的錯誤率）

分析完了，問題不只是「時態不好」這麼簡單。具體來說：

- 68% 的錯誤集中在「完成式 vs 過去式」的選擇
- 很多學生把 "I have done" 和 "I did" 混用
- 根本原因：學生不理解「動作跟現在有沒有連結」這個判斷標準

一般練習題只練時態的「形式」（have + p.p.），但沒辦法修正這個觀念問題。

我幫你出一組專門針對這個盲點的題目，不只是填空，
而是要學生「判斷並解釋為什麼用這個時態」。
```

**旁白：**
「你看到了嗎？老師說的是『出 10 題時態練習』，但 Claude 回答的是『問題不是時態，是完成式觀念混淆』。它把問題從表面的『時態不好』，深挖到具體的認知盲點：學生不理解動作跟現在的連結。然後出的題目完全不一樣——不是一般的填空題，而是要學生判斷並解釋。」

**字幕：**
驚喜時刻：AI 深挖盲點！
老師說：「出 10 題時態練習」
AI 說：「問題不是時態——是完成式觀念混淆」
→ 出的題目完全不同！

### 場景 4：三難度題組（40 秒）

**畫面：**
展示 Claude 生成的三個難度等級的題組。

**旁白：**
「基於這個分析，Claude 出了三個難度的題組。注意每一題都針對那個具體盲點：學生什麼時候該用完成式、什麼時候該用過去式。」

**使用者輸入：**
```
很好，那請幫我出三個難度各 5 題：
- 初級：選擇題，判斷該用完成式還是過去式
- 中級：填空題，填入正確時態並寫一句理由
- 高級：短文改錯，找出時態用法錯誤並修正

每題都要有詳細解析，情境要貼近台灣中學生的生活
```

**Claude 回應：**
```
好的！以下是針對「完成式 vs 過去式」盲點設計的題組：

【初級：選擇題】

1. 昨天我 _____ 那部電影了。(watched / have watched)
   答案：watched
   解析：「昨天」是明確的過去時間點，動作已經結束，
   跟現在沒有連結，所以用過去式。

2. 我 _____ 那部電影三次了。(watched / have watched)
   答案：have watched
   解析：「三次了」表示從過去到現在的累積經驗，
   動作跟現在有連結（你現在是一個看過三次的人），
   所以用完成式。
...
```

### 場景 5：老師審題與修改（30 秒）

**畫面：**
林老師快速瀏覽題目，發現一題不太合適。

**旁白：**
「AI 出題，老師審題。這是最有效率的搭配。林老師發現第 4 題對國中生來說太難了，直接告訴 Claude 修改。」

**使用者輸入：**
```
中級第 4 題太難了，改成更簡單的情境，用去旅行的例子
```

**Claude 回應：**
```
已修改中級第 4 題：

4. I _____ (visit) Japan twice. I _____ (go) there last summer.
   答案：have visited / went
   解析：第一句是「到目前為止的經驗累積」→ 完成式；
   第二句有「last summer」明確的過去時間 → 過去式。
```

### 場景 6：生成答案卷（20 秒）

**使用者輸入：**
```
很好！請同時生成：
1. 學生版試卷（只有題目）
2. 老師版答案卷（只有答案，不含解析）
3. 完整版（含答案和解析，老師自己參考用）

存到 ~/horizon-academy/exam-materials/
```

**旁白：**
「最後一步，請 Claude 生成三個版本：學生考試用的、老師改考卷用的、老師自己備課參考的。一次搞定。」

### 場景 7：收尾（20 秒）

**旁白：**
「今天最大的收穫不是『AI 會出題』這件事，而是 AI 會先分析學生的認知盲點，然後針對盲點設計題目。下次出題之前，先讓 Claude 看看學生的成績資料，它會告訴你真正該考什麼。」

## 延伸練習

### 練習 1：你的科目版本
用你最近一次考試的成績資料，讓 Claude 分析學生的錯誤模式，再針對盲點出題。

### 練習 2：作業設計
讓 Claude 設計一份有趣的回家作業（不只是題目，還有說明、範例和評分標準）。

### 練習 3：題庫累積
建立一個題庫資料夾：讓 Claude 每週根據最新的教學進度生成 10 道練習題，存入 `~/horizon-academy/question-bank/`，累積一學期的題庫。
