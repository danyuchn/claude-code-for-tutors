# 課程 2-1：批次生成個人化家長回覆

AI 批次生成不是「複製貼上換名字」——它能從多份資料交叉比對，每封信都真正個人化。

## 課程來源

改編自原始案例：使用者要求 AI 為多位學生提供個別化回覆。AI 主動從雲端讀取學生資料，從成績和情緒雙維度分析，生成有同理心、個人化的回覆——不只是「加油」，而是根據每位學生的具體數據給出不同建議。核心展示：AI 同時讀取多個資料來源（並行工具呼叫），交叉比對後產出真正有差異的個人化內容。

## 📋 課程資訊
- **適合對象**：完成 Module 1 的學員
- **所需時間**：15 分鐘
- **學習重點**：
  - AI 批次生成可以做到真正個人化，不只是換名字
  - 提供越多資料維度，回覆越有深度
  - AI 能同時讀取多份資料做交叉分析
  - 批次任務的實際時間節省計算
- **工具需求**：Claude Code，`exam-scores.csv`、`student-roster.csv`、`parent-survey.csv`
- **本課產出**：25 封個人化家長月底回饋信
- **教師獨有場景**：是

## 🎬 拍攝腳本

### 場景 1：情境介紹——老師的月底噩夢（30 秒）

**畫面：**
林老師看著行事曆，月底到了，她需要發 25 封家長回饋信

**旁白：**
「每個月底，林老師都要寫家長回饋信。25 位學生，每封信平均花 10 分鐘——加起來超過 4 小時。而且她知道，如果每封都一樣，家長一眼就看得出來。」

**字幕：**
```
25 封信 x 10 分鐘 = 250 分鐘（超過 4 小時）
目標：5 分鐘搞定，而且每封都不一樣
```

---

### 場景 2：傳統方式 vs. AI 方式（30 秒）

**畫面：**
左邊：傳統方式——複製同一封信、只改名字
右邊：AI 方式——每封信內容不同

**旁白：**
「傳統做法是寫一封模板，複製 25 次，把名字改掉。但家長一比對就知道——怎麼我家孩子和隔壁小明收到的信一模一樣？AI 的做法完全不同：它會讀每個孩子的資料，生成真正不一樣的內容。」

---

### 場景 3：一次讀取三份資料——驚喜時刻（60 秒）

**使用者輸入：**
```
幫我為這25位學生的家長各寫一封月底回饋信
```

**Claude 回應：**
```
好的，讓我先讀取相關資料。

[Tool: Read] .claude/horizon-academy/sample-data/exam-scores.csv
[Tool: Read] .claude/horizon-academy/sample-data/student-roster.csv
[Tool: Read] .claude/horizon-academy/sample-data/parent-survey.csv

我找到了 25 位學生的完整資料，包含：
- 三次月考成績與成績趨勢
- 出席率和作業繳交率
- 家長問卷回饋（滿意度和具體意見）

我會從「成績趨勢」和「家長關注重點」兩個維度分析，
為每位家長生成個人化回饋信。讓我開始。
```

**旁白：**
「注意看！林老師只說了一句話，Claude 就同時讀取了三份資料——成績、學生名冊、家長問卷。它不是只看成績，而是交叉比對三份資料。這就是 AI 的真正優勢：它能同時處理多個資料來源。」

**字幕：**
```
驚喜時刻：
AI 同時讀取 3 份資料（並行工具呼叫）
成績 + 名冊 + 問卷 = 360 度全面分析
```

---

### 場景 4：每封信都不一樣——真正的個人化（80 秒）

**Claude 回應（示意，展示 3 封代表性的信）：**

**信件 1：進步型——王小明（72 → 85 → 88）**
```
親愛的王爸爸媽媽：

小明這個月在英文上的表現讓我很欣慰。從學期初的 72 分到現在的 88 分，
這不是運氣，是他每天在課堂上越來越願意舉手發言、下課主動來問問題的結果。

特別想跟您分享，他最近在閱讀理解方面進步最明顯。我注意到他開始會
自己劃重點、做筆記了——這是很棒的自主學習習慣。

他的出席率 95%、作業繳交率 90%，都很穩定。
如果能再把作業完成度提高一些，下次月考 90 分以上完全有可能。

繼續保持這個節奏！

林欣怡老師
```

**信件 2：需要關注型——張志豪（63 → 60 → 55）**
```
親愛的張媽媽：

我想主動跟您聊聊志豪最近的學習狀況。

從成績來看，這學期他的分數有些下降（63 → 60 → 55），
我也注意到他的出席率（75%）和作業繳交率（65%）偏低。
我想了解是不是有什麼我不知道的原因——
比如身體不舒服、或是對上課方式有什麼想法。

我在問卷中看到您提到擔心教學方式不適合志豪，
我非常重視這個回饋。我想跟您約個時間聊聊，
一起討論怎麼幫志豪找到最適合他的學習方式。

您方便這週安排一次 15 分鐘的面談嗎？

林欣怡老師
```

**信件 3：穩定型——許淑芬（82 → 84 → 83）**
```
親愛的許爸爸媽媽：

淑芬這學期的表現一直很穩定——82、84、83，
三次月考都維持在 80 分以上，出席率 95%、作業繳交率 92%，
在班上是非常可靠的學生。

您在問卷中提到希望月考前多給複習重點，
這個建議我收到了。下次月考前一週，
我會整理一份重點複習清單發給全班家長。

對淑芬來說，她目前的基礎很穩固。
如果想再往上突破到 90 分，我建議可以多做一些延伸閱讀，
我之後可以推薦幾本適合她程度的英文讀物。

林欣怡老師
```

**旁白：**
「看到差別了嗎？三封信完全不一樣。王小明的信強調進步和鼓勵；張志豪的信直接引用了家長問卷的擔憂，主動約面談；許淑芬的信回應了問卷中『希望多給複習重點』的建議。每封信都交叉引用了成績資料和問卷回饋——這不是複製貼上能做到的。」

**字幕：**
```
真正的個人化：
- 進步型：肯定具體進步幅度 + 鼓勵
- 需關注型：引用家長問卷擔憂 + 主動約面談
- 穩定型：回應問卷建議 + 提供突破方向
```

---

### 場景 5：品質確認與微調（30 秒）

**使用者輸入：**
```
張志豪那封語氣再溫暖一點，不要讓家長覺得是被約談。
還有，每封信都幫我加上「有任何問題歡迎隨時 LINE 我」這句話
```

**旁白：**
「批次生成之後，可以針對特定幾封做微調。AI 會記住之前的所有信件，只修改你指出的部分。這比自己重寫 25 封快多了。」

---

### 場景 6：時間計算——驚喜數字（20 秒）

**旁白：**
「最後算一下省了多少時間。傳統做法：25 封信，每封 10 分鐘，至少 4 小時。用 AI：從下指令到微調完成，不到 10 分鐘。而且每封信的品質更高——因為它交叉比對了三份資料，這是人工很難做到的。」

**字幕：**
```
傳統方式：25 封 x 10 分鐘 = 250 分鐘
AI 方式：下指令 + 微調 = 不到 10 分鐘
節省時間：240 分鐘（4 小時）
品質提升：每封信交叉引用 3 份資料
```

---

### 場景 7：總結（20 秒）

**字幕：**
```
AI 批次生成的關鍵：
1. 提供越多資料維度，個人化程度越高
2. AI 會同時讀取多份資料做交叉分析
```

## 💡 延伸練習

### 練習 1：基礎——先試 3 封
選出班上成績差異最大的 3 位學生，讓 Claude 生成個人化回饋信。觀察三封信的差異程度。

### 練習 2：進階——加入更多維度
在回饋信中同時提及成績、出席率、家長問卷意見，讓信件更有深度。試試給 Claude 更多資料，觀察信件品質的變化。

### 練習 3：挑戰——建立可重複使用的流程
把這次用的指令存成模板。下個月只需要更新成績資料，就能直接生成新一批回饋信。

## 📖 常見問題

### Q：25 封信，家長不會發現是 AI 寫的嗎？
A：如果只是換名字，當然會被發現。但如果每封信提到的問題、建議、鼓勵的方向都不同——比如引用了家長自己在問卷中提出的建議——家長很難覺得這是批次生成的。

### Q：可以加入老師的個人語氣嗎？
A：可以！在指令裡加一句「用溫暖、像朋友聊天的語氣，偶爾用口語化的詞」，Claude 就會調整風格。也可以先寫一封你滿意的信當範例，讓 Claude 模仿你的語氣。

### Q：如果某封信需要特別處理怎麼辦？
A：直接說「張志豪那封幫我重寫，語氣更溫和一點」。AI 會記住所有信件的上下文，只改你指定的那封。
