# 課程 2-6：搜尋和找回舊資料

讓 Claude 在你的電腦裡搜尋，找到那份「記得有，但找不到」的教材。

## 📋 課程資訊
- **適合對象**：完成課程 2-5 的學員
- **所需時間**：10 分鐘
- **學習重點**：
  - 學會用 Claude 搜尋本機文件
  - 了解如何用關鍵字和條件縮小搜尋範圍
  - 建立教材索引，讓未來的搜尋更快速
- **工具需求**：Claude Code
- **本課產出**：常用教材索引清單（`teaching-materials-index.md`）
- **教師獨有場景**：否（通用技能）

---

## 🎬 拍攝腳本（骨架）

### 場景 1：找不到教材的困境（20 秒）
> 林老師想用一份幾年前做的環保主題閱讀理解
> 翻了 10 分鐘的電腦，還是找不到

### 場景 2：讓 Claude 搜尋（35 秒）

**關鍵指令範例：**
```
請在以下資料夾搜尋我想找的教材：
- 搜尋路徑：~/Documents 和 ~/Desktop
- 關鍵字：「閱讀理解」或「reading comprehension」
- 可能主題：環保、environment、ecological
- 檔案格式：.docx 或 .pdf
- 時間範圍：2022-2024 年建立的文件

找到後列出所有可能相關的檔案，包含完整路徑
```

### 場景 3：整理搜尋結果（30 秒）
> Claude 找到 8 個相關檔案
> 讓 Claude 生成摘要，林老師快速確認哪個是要找的

### 場景 4：建立教材索引（30 秒）
> 建立索引表格，方便下次快速找到

**關鍵指令範例：**
```
請幫我把找到的教材整理成索引表格，欄位：
- 檔案名稱
- 主題類別（文法/閱讀/寫作/口語）
- 適合年級
- 完整路徑
- 備注

儲存到 ~/horizon-academy/teaching-materials-index.md
```

---

## 💡 延伸練習

### 練習 1：搜尋你的備課資料
讓 Claude 搜尋你電腦上的備課資料，建立一份教材清單。

### 練習 2：按主題分類
把找到的教材按照「文法、閱讀、寫作、口語」分類整理。

### 練習 3：定期更新索引
每個學期末，更新一次教材索引，加入新製作的教材。

---

## 🎯 學習目標檢查

完成這一課後，你應該能夠：
- [ ] 用關鍵字和條件讓 Claude 搜尋本機文件
- [ ] 快速確認搜尋結果中的相關檔案
- [ ] 建立並儲存教材索引文件
