# 課程 2-6：搜尋和找回舊資料

讓 Claude 幫你在電腦裡大海撈針——用模糊描述找到那份「記得有做過，但忘記放哪裡」的教材。

## 課程資訊
- **適合對象**：完成課程 2-5 的學員
- **所需時間**：12 分鐘
- **學習重點**：
  - 學會用模糊描述讓 Claude 搜尋本機文件
  - 體驗 AI 的搜尋自我修正能力——找到類似但不對的結果時會主動調整方向
  - 掌握建立教材索引的方法
- **工具需求**：Claude Code
- **本課產出**：常用教材快速搜尋技巧 + 整理好的教材索引
- **教師獨有場景**：否（通用技能）

---

## 拍攝腳本

### 場景 1：找不到教材的困境（20 秒）

**畫面：**
林老師在電腦上翻找檔案，開了一個又一個資料夾，表情越來越焦急。

**旁白：**
「林老師記得去年有做過一份關於升學的資料，但翻了十分鐘的電腦，就是找不到。她只記得『好像是一份有圖表的東西，有各大學的錄取分數』。這種模糊的記憶，要自己找起來真的是大海撈針。」

**字幕：**
「我記得有做過一份...但忘記放哪裡了」
每個老師的日常困擾

### 場景 2：用模糊描述搜尋（35 秒）

**畫面：**
林老師輸入模糊的搜尋需求。

**旁白：**
「不用記得檔名、不用記得資料夾，直接用你記得的片段描述告訴 Claude。」

**使用者輸入：**
```
我記得去年有做過一份關於升學的資料，你幫我找一下
```

### 場景 3：搜尋自我修正的驚喜時刻（55 秒）

**畫面：**
Claude 搜尋後回報結果，但不是林老師要找的。

**Claude 回應：**
```
[Tool: Glob] 搜尋所有含「升學」的檔案

我找到了一份「升學諮詢FAQ.md」，在 ~/horizon-academy/counseling/ 裡。
不確定是不是你要的——這是一份常見問題清單，
裡面有「什麼時候開始準備」「需要哪些文件」之類的問答。

你要找的是這個，還是其他類型的文件？
```

**旁白：**
「注意 Claude 的回應。它找到了一份相關的檔案，但沒有直接說『找到了！』。它說的是『不確定是不是你要的』，然後描述了它找到的內容，讓你判斷。這很重要——它知道搜尋結果可能不對。」

**使用者輸入：**
```
不是，應該是一份圖表，有各大學錄取分數的那種
```

**Claude 回應：**
```
了解，你要找的是有數據的文件，不是 FAQ。讓我調整搜尋方向。

[Tool: Glob] 搜尋 .xlsx, .csv, .pptx 檔案

找到了！「2024_大學申請數據分析.xlsx」
位置：~/horizon-academy/counseling/data/
建立日期：2024 年 3 月
大小：245 KB

裡面有 15 所大學的錄取分數分布，還有你班上學生的錄取記錄。
要我幫你打開看看，還是幫你整理裡面的資料？
```

**旁白：**
「這就是今天的驚喜時刻。老師描述得很模糊：『去年做過的、有圖表的、有錄取分數的那種』。Claude 第一次找到的是 FAQ，知道不對；老師補了一句線索，它就調整方向，從搜尋文字檔改成搜尋 Excel 和簡報檔，最後找到了。整個過程就像跟助教說：『幫我找那個東西。』『這個嗎？』『不是，是有表格的那個。』『喔，找到了！』」

**字幕：**
驚喜時刻：搜尋自我修正！
第 1 次：找到 FAQ → 「不確定是不是你要的」
老師補充線索：「有圖表的那種」
第 2 次：調整搜尋 → 找到 Excel 檔案！

### 場景 4：進階搜尋技巧（30 秒）

**畫面：**
展示更精確的搜尋方式。

**旁白：**
「學會了基本搜尋之後，我們來看看更精確的搜尋方式。你可以用多個條件來縮小範圍。」

**使用者輸入：**
```
幫我搜尋所有跟英文閱讀有關的教材：
- 搜尋範圍：~/horizon-academy/ 和 ~/Documents/
- 關鍵字：閱讀理解、reading comprehension、reading practice
- 檔案類型：Word 或 PDF
- 時間：2023 年之後建立的
```

**Claude 回應：**
```
[Tool: Glob] 搜尋 .docx 和 .pdf
[Tool: Grep] 搜尋檔案內容

找到 12 個相關檔案：

~/horizon-academy/teaching-materials/reading/
  1. 國一-閱讀理解-環保主題-素材.docx（2024-03）
  2. 國二-閱讀理解-科技主題-測驗.docx（2024-05）
  3. 國三-閱讀理解-旅行主題-素材.docx（2023-09）

~/Documents/
  4. Reading-Comprehension-Practice-Set-1.pdf（2023-11）
  5. 英文閱讀素材整理.docx（2024-01）
  ...

要我列出完整清單，還是幫你建立一份教材索引？
```

### 場景 5：建立教材索引（35 秒）

**畫面：**
讓 Claude 建立可以未來快速查找的索引。

**旁白：**
「找到教材之後，我們做一件更有價值的事：建立教材索引。以後就不用每次都搜尋了。」

**使用者輸入：**
```
幫我把找到的所有教材整理成索引表格，欄位：
- 檔案名稱
- 主題類別（文法/閱讀/寫作/口語）
- 適合年級
- 完整路徑
- 備注

儲存到 ~/horizon-academy/teaching-materials-index.md
```

**Claude 回應：**
```
[Tool: Write] teaching-materials-index.md

已建立教材索引！共收錄 38 份教材：

| 檔案名稱 | 主題 | 年級 | 路徑 | 備注 |
|---------|------|------|------|------|
| 閱讀理解-環保主題.docx | 閱讀 | 國一 | ~/horizon-academy/... | 含素材和測驗 |
| Grammar_L3_final.docx | 文法 | 國一 | ~/horizon-academy/... | 第三課文法 |
| ...

以後要找教材，可以直接跟我說：
「索引裡有沒有國二的閱讀素材？」
我就能馬上告訴你。
```

### 場景 6：用索引快速查找（20 秒）

**使用者輸入：**
```
索引裡有沒有適合國三的口語練習教材？
```

**Claude 回應：**
```
[Tool: Read] teaching-materials-index.md

有 2 份：
1. 「國三-口語報告-評分量表.docx」在 ~/horizon-academy/slides/
2. 「Oral-Practice-Topics.pdf」在 ~/Documents/

第一份是評分用的量表，第二份是口語練習的主題清單。
要用哪一份？
```

**旁白：**
「有了索引，找教材從『大海撈針十分鐘』變成『問一句話兩秒鐘』。」

### 場景 7：收尾（20 秒）

**旁白：**
「今天學了兩件事。第一，Claude 可以用你模糊的描述來搜尋檔案，而且找錯了會自己修正方向，不需要你一直糾正它。第二，與其每次都搜尋，不如一次建好索引，以後問一句話就能找到。」

## 延伸練習

### 練習 1：搜尋你的備課資料
讓 Claude 搜尋你電腦上的備課資料，看看有沒有你忘記的好教材。

### 練習 2：按主題分類索引
把找到的教材按照「文法、閱讀、寫作、口語」分類整理成索引。

### 練習 3：定期更新索引
每個學期末，讓 Claude 掃描一次教材資料夾，更新索引，加入新製作的教材。
