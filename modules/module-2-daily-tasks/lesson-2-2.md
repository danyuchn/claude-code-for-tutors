# 課程 2-2：寫出有老師味的社群貼文

學習讓 AI 寫出「看不出是 AI 寫的」文案——秘訣在去 AI 味。

## 課程資訊
- **適合對象**：完成課程 2-1 的學員
- **所需時間**：12 分鐘
- **學習重點**：
  - AI 第一稿往往「太正式」「太全面」——這是正常的
  - 去 AI 味的具體做法：刪形容詞、加細節、縮短句子
  - 如何告訴 AI 你想要的語氣（舉例比描述更有效）
  - 修改前後對比能幫助理解什麼是「AI 味」
- **工具需求**：Claude Code
- **本課產出**：3 平台版本的鋼琴發表會宣傳貼文（IG / FB / LINE 群）
- **教師獨有場景**：否（通用技能，但用教師場景示範）

---

## 拍攝腳本

### 場景 1：王老師的困擾（25 秒）

**畫面：**
王老師（音樂老師）要幫學校的鋼琴發表會寫宣傳貼文

**旁白：**
「王老師是明日學院的音樂老師，下個月有場鋼琴發表會。她需要在 Instagram、Facebook 和 LINE 群發宣傳文。她試過自己寫，但總覺得不夠有感覺；她也試過用 AI，但寫出來的東西太像廣告，一看就是 AI 的。」

---

### 場景 2：先看看 AI 的「原味」——典型 AI 文案（40 秒）

**使用者輸入：**
```
幫我為下個月的鋼琴發表會寫一篇 Instagram 貼文，
要讓家長感覺到那個緊張又期待的氛圍
```

**Claude 回應（AI 原味初稿）：**
```
精彩演出，不容錯過！

我們的學生們經過長達數月的精心準備，
即將在年度鋼琴發表會上展現他們的音樂才華與卓越成就。

每一個音符都凝聚著汗水與努力，
每一段旋律都訴說著成長的故事。

這不僅僅是一場演出，
更是孩子們展現自我、綻放光芒的珍貴時刻。

誠摯邀請您蒞臨見證孩子的成長！

#鋼琴發表會 #音樂教育 #明日學院 #才華綻放 #成長故事
```

**旁白：**
「這就是典型的 AI 文案。內容沒有錯，但你讀完有什麼感覺？『精彩演出不容錯過』——這是任何活動都能用的句子。『卓越成就』『綻放光芒』——這些詞誰都可以寫，跟鋼琴發表會完全沒有關係。」

**字幕：**
```
AI 味特徵：
- 大量形容詞（卓越、精彩、珍貴）
- 空洞的排比句
- 任何活動都能套用的萬用語句
- 缺乏具體細節
```

---

### 場景 3：下達「去 AI 味」指令（40 秒）

**使用者輸入：**
```
太 AI 了。幫我改得口語一點，像老師自己發的。
刪掉所有形容詞堆疊，加入一個真實的排練小故事
```

**Claude 回應（修改後）：**
```
孩子們練了三個月，終於要上台了。

昨天最後一次排練，有個孩子彈到一半忽然停下來——
不是因為彈錯，是因為太緊張。
我走過去跟他說：「沒關係，到時候台下坐的都是最愛你的人。」
他笑了一下，從頭彈了一遍，比之前好聽十倍。

3/15（六）下午兩點，明日學院多功能廳。
歡迎來看他們發光。

#鋼琴發表會 #明日學院
```

**旁白：**
「差別感受到了嗎？第二版有一個具體的排練故事——雖然是 AI 虛構的，但完全可信。『彈到一半停下來』、『台下坐的都是最愛你的人』——這些細節讓你看到畫面、感受到溫度。而且注意，hashtag 從 5 個減到 2 個。」

**字幕：**
```
驚喜時刻：修改前後對比
- 「精彩演出，不容錯過」→ 刪除（行銷腔）
- 「卓越成就」→ 刪除（書面體）
- 加入排練小故事 → 讓讀者有畫面感
- 5 個 hashtag → 2 個（少即是多）
```

---

### 場景 4：AI 解釋它改了什麼——去 AI 味教學（50 秒）

**使用者輸入：**
```
列出你做了哪些修改，解釋為什麼原來的版本有 AI 味
```

**Claude 回應：**
```
以下是主要修改和原因：

1.「精彩演出，不容錯過」→ 刪除
  原因：這是行銷文案的萬用開頭，任何活動都能用，
  讀者看到就知道是模板。

2.「長達數月的精心準備」→「練了三個月」
  原因：「長達數月」是書面體，沒人講話會這樣說。
  直接說「三個月」更具體也更口語。

3.「展現音樂才華與卓越成就」→ 刪除
  原因：形容詞堆疊是 AI 最常見的特徵。
  真正的老師不會這樣形容學生——他們會說具體的事。

4. 加入排練小故事
  原因：真人發文最大的特徵是有「只有你知道的細節」。
  一個「彈到一半停下來」的小故事，
  比十個形容詞更能讓讀者感受到現場。

5. 結尾「歡迎來看他們發光」
  原因：用短句收尾、帶一點詩意但不刻意，
  比「誠摯邀請您蒞臨」自然一百倍。

AI 味自我評分：
- 初稿：8/10（非常 AI）
- 修改後：2/10（接近真人）
```

**旁白：**
「這段解釋本身就是一堂去 AI 味的寫作課。記住三個原則：第一，刪掉形容詞堆疊；第二，加入具體細節；第三，句子越短越好。」

**字幕：**
```
去 AI 味三原則：
1. 刪掉形容詞（卓越、精彩、珍貴 → 全部刪掉）
2. 加入細節（只有你知道的小故事）
3. 縮短句子（「誠摯邀請您蒞臨」→「歡迎來看」）
```

---

### 場景 5：三平台版本——一次生成三個不同風格（50 秒）

**使用者輸入：**
```
很好！現在幫我生成三個平台版本：
- Instagram：200 字 + 2-3 個 hashtag，有畫面感
- Facebook：500 字，適合家長轉發，加上活動細節
- LINE 群：100 字以內，簡短通知，口氣像傳訊息給朋友
```

**Claude 回應（示意，展示 LINE 群版本）：**
```
【LINE 群版本】

各位爸爸媽媽，3/15（六）下午兩點
孩子們的鋼琴發表會在多功能廳～

他們練了好久，昨天排練的時候
我看好幾個孩子手都在抖（但彈得真的很好）

歡迎來幫他們加油！
有問題私訊我就好
```

**旁白：**
「三個版本的語氣完全不同。Instagram 有畫面感、Facebook 有完整細節適合轉發、LINE 群像在跟朋友傳訊息。但三個版本都有同一個特點：沒有 AI 味。因為我們已經教會 AI 該用什麼語氣了。」

---

### 場景 6：舉例比描述更有效——進階技巧（30 秒）

**旁白：**
「最後分享一個進階技巧。如果你要 AI 模仿你的語氣，與其描述『溫暖、口語、有人情味』，不如直接給它一個你以前寫過的貼文當範例。比如說：」

**使用者輸入：**
```
這是我之前發的一篇貼文，模仿這個語氣：
「下課後有個學生跑來跟我說：老師你今天教的那首曲子好好聽。
他沒有說哪裡好聽，但他的眼睛在發光。
有時候教音樂最值得的就是這種時刻。」
```

**旁白：**
「一個範例比十句描述更精準。AI 會從你的文字中學到節奏、用詞、甚至標點符號的風格。」

**字幕：**
```
進階技巧：
「模仿我的語氣」+ 一個真實範例
比說「溫暖、口語、有人情味」更有效
```

---

### 場景 7：總結（20 秒）

**字幕：**
```
去 AI 味完整流程：
1. 先讓 AI 生成初稿（它一定很 AI）
2. 說「太 AI 了，改口語一點」
3. 要求列出修改對比（學習什麼是 AI 味）
4. 給一個你的真實範例讓 AI 模仿
5. 生成多平台版本
```

## 延伸練習

### 練習 1：找出 AI 味
讓 Claude 生成任何主題的文案，然後請它找出「AI 味最重的 5 個詞」並替換。觀察它的修改邏輯。

### 練習 2：描述你的風格
用 3-5 個句子描述你自己的說話風格，然後讓 Claude 用你的語氣寫一篇社群貼文。比較看看像不像你。

### 練習 3：三平台差異
針對同一件事（例如：期末成果展），為 Instagram、Facebook、LINE 群各寫一版。注意三個版本的字數、語氣、細節程度都要不同。

## 常見問題

### Q：AI 加入的「小故事」是虛構的，可以用嗎？
A：看情況。如果故事是「可能發生的」（排練時有孩子緊張）而且不涉及特定學生，通常沒問題。但如果你覺得不妥，可以把真實發生的事告訴 AI，讓它改寫成更有溫度的版本。

### Q：每次都要手動去 AI 味嗎？
A：第一次需要教 AI 你的風格。之後可以把「去 AI 味規則」存成指令模板，每次用的時候直接套用。

### Q：怎麼判斷一段文字有沒有 AI 味？
A：問自己兩個問題：1）這段話是不是任何主題都能用？（如果是，那就是 AI 味）2）裡面有沒有「只有我知道的細節」？（如果沒有，就加一個）
