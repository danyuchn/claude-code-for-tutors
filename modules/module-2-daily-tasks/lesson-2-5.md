# 課程 2-5：快速整理教學資料（課程規劃）

把腦中零散的教學想法，讓 Claude 整理成清晰的 12 週課程大綱。

## 📋 課程資訊
- **適合對象**：完成課程 2-4 的學員
- **所需時間**：13 分鐘
- **學習重點**：
  - 學習「Brain Dump」技巧——先亂說，再整理
  - 讓 AI 把非結構化的想法轉為結構化文件
  - 建立可重複使用的課程規劃框架
- **工具需求**：Claude Code
- **本課產出**：12 週英文課程大綱（含主題、教材、評量）
- **教師獨有場景**：✅ 是

---

## 🎬 拍攝腳本（骨架）

### 場景 1：課程規劃的困境（25 秒）
> 林老師有很多教學想法，但整理成文件就花了半天
> 展示她的手寫筆記——很零散但有很多好想法

### 場景 2：Brain Dump 技巧（40 秒）
> 引導林老師「先把腦中的想法全部說出來，不用管順序」

**關鍵指令範例：**
```
我要規劃下學期英文課，以下是我的想法（順序很亂，請幫我整理）：

- 前面幾週要複習文法基礎，特別是時態
- 中間我想做主題閱讀，有旅行、科技、環保三個主題
- 後面要讓學生做口頭報告，練習口語
- 全學期都要背單字，但不要死背，要用情境
- 每個月有一篇寫作作業
- 期末要有一個大project，可以是簡報或表演
- 教材用 Let's Talk 課本為主，補充時事文章
- 共 12 週，每週 3 節課

請幫我整理成有週次的課程大綱，格式：週次、主題、教材、學習目標、評量方式
```

### 場景 3：大綱結果（35 秒）
> 展示整齊的 12 週大綱表格
> 強調：每週有明確主題和可測量的學習目標

### 場景 4：細化某一週（25 秒）
> 「第 1-4 週的複習計畫，每週要具體列出教學活動」

---

## 💡 延伸練習

### 練習 1：你的下學期課程
用 Brain Dump 技巧，把你下學期的教學想法說給 Claude 聽，讓它整理成大綱。

### 練習 2：建立課程模板
讓 Claude 把這次的大綱格式存成模板，以後每學期只需要修改內容。

### 練習 3：和同事分享
把 Claude 整理的大綱分享給同年段的老師，讓他們給意見，再讓 Claude 更新。

- [ ] 讓 Claude 整理成有結構的週次大綱
- [ ] 針對特定週次進行細化
