# 課程 2-5：快速整理教學資料

讓 Claude 幫你整理散亂的教材資料夾——不只分類，還會主動發現重複和放錯位置的檔案。

## 課程來源

改編自 Claude Code 實戰對話：使用者請 AI 整理一個有 47 個檔案的雲端硬碟資料夾，AI 不僅按規則分類，還主動用 MD5 比對發現重複檔案，並回報命名不一致和放錯位置的問題。原始案例展示了 AI 在執行任務時的「主動發現問題」能力。

---

## 📋 課程資訊
- **適合對象**：完成課程 2-4 的學員
- **所需時間**：15 分鐘
- **學習重點**：
  - 學會讓 AI 整理大量檔案並建立分類結構
  - 體驗 AI 主動發現問題的能力（重複檔案、命名不一致、分類錯誤）
  - 了解 AI 如何制定整理計畫並逐步執行
- **工具需求**：Claude Code
- **本課產出**：整理好的教材資料夾結構 + 重複/問題檔案報告
- **教師獨有場景**：否（通用技能）

## 🎬 拍攝腳本

### 場景 1：教材資料夾的混亂（25 秒）

**畫面：**
展示林老師的教材資料夾，檔案散落一地，命名混亂。

**旁白：**
「教了五年英文，林老師的教材資料夾已經變成一座小型垃圾山。各種版本的講義、重複的檔案、放錯資料夾的考卷，光看就頭痛。今天我們讓 Claude 來當整理專家。」

**字幕：**
47 個檔案，5 年累積
命名混亂、重複不知道、分類全靠感覺

### 場景 2：交代整理任務（35 秒）

**畫面：**
林老師輸入整理需求。

**旁白：**
「跟 Claude 說你要整理什麼，不用自己先分類，直接讓 AI 來看。」

**使用者輸入：**
```
我的教材資料夾一團亂，幫我把 ~/horizon-academy/teaching-materials/ 整理好。

我的教材大概分成這幾類：
- 文法講義
- 閱讀素材
- 考卷和練習題
- 課程簡報
- 學生作品範例

請先看看裡面有什麼，告訴我你打算怎麼整理，先不要動
```

### 場景 3：AI 制定整理計畫（40 秒）

**畫面：**
Claude 掃描資料夾後，回報它的整理計畫。

**Claude 回應：**
```
[Tool: Bash] ls -la ~/horizon-academy/teaching-materials/

我掃描了資料夾，找到 47 個檔案。在開始整理之前，
我先告訴你我發現的幾個狀況：

📁 整理計畫：
1. 建立 5 個分類資料夾（文法、閱讀、考卷、簡報、學生作品）
2. 依檔名和內容自動分類
3. 統一命名格式：「年級-主題-類型.副檔名」

⚠️ 但我發現了一些問題需要你先確認：

問題 1：重複檔案
「第三課Grammar練習.docx」和「Grammar_L3_final.docx」
→ 檔名不同，但內容幾乎一樣。建議保留後者（較新）？

問題 2：多版本檔案
有 3 個檔案都叫「期中考題」，修改日期分別是 2023、2024、2025
→ 我保留最新版本，舊版移到「archive」資料夾？

問題 3：無法自動分類
有 8 份講義沒有年級標記，我無法判斷屬於哪個年級
→ 先放在「待分類」資料夾，等你有空再標注？
```

**旁白：**
「注意 Claude 做了什麼。老師只說了『幫我整理』，但 Claude 不只準備分類，還主動發現了三個問題：有重複的檔案、有多個版本的考題、有無法分類的講義。而且它用問號結尾——在請你確認要怎麼處理，不會自作主張。」

### 場景 4：重複檔案偵測的驚喜時刻（50 秒）

**畫面：**
林老師確認後，Claude 開始整理，並在過程中又發現新問題。

**使用者輸入：**
```
好的，你說的三個問題：
1. 重複的保留新版
2. 多版本的保留最新，舊版放 archive
3. 無法分類的放「待分類」

開始整理吧
```

**Claude 回應：**
```
開始整理！

[Tool: Bash] mkdir -p grammar reading exams slides student-work archive pending

移動文法講義中...
移動閱讀素材中...
移動考卷中...

⚠️ 整理過程中又發現新問題：

「閱讀理解-環保主題.docx」出現在兩個地方：
根目錄有一份，「考卷」子資料夾裡也有一份。
我比對了內容——根目錄那份是閱讀素材（純文章），
考卷資料夾那份是閱讀測驗（文章 + 題目）。
雖然檔名一樣，但其實是不同文件！

→ 我把它們分別放到「閱讀素材」和「考卷」資料夾，
並在檔名加上後綴區分：
- reading/閱讀理解-環保主題-素材.docx
- exams/閱讀理解-環保主題-測驗.docx
```

**旁白：**
「這就是今天的驚喜時刻。老師只說了『整理教材』，但 Claude 在整理過程中發現了兩份同名但不同內容的檔案。它沒有直接覆蓋、沒有隨便刪掉，而是比對內容後告訴老師：『這兩份檔名一樣，但其實是不同文件。』老師自己都不知道有這個問題！」

**字幕：**
驚喜時刻：AI 主動發現問題！
同名檔案 → 比對內容 → 發現是不同文件
老師自己都不知道的重複問題，AI 幫你抓出來

### 場景 5：整理結果報告（35 秒）

**畫面：**
Claude 展示整理完成的結果。

**Claude 回應：**
```
整理完成！最終結果：

📁 teaching-materials/
├── grammar/          12 個檔案（國一到高三文法講義）
├── reading/           8 個檔案（閱讀素材，按主題分類）
├── exams/            11 個檔案（考卷和練習題）
├── slides/            6 個檔案（課程簡報）
├── student-work/      3 個檔案（學生作品範例）
├── archive/           4 個檔案（舊版本，保留備查）
└── pending/           3 個檔案（待你確認分類）

📊 處理摘要：
- 分類完成：40 個檔案
- 發現重複並刪除：2 組（保留較新版本）
- 發現同名不同檔：1 組（已加後綴區分）
- 命名統一化：15 個檔案（改為「年級-主題-類型」格式）
- 待確認：3 個檔案

需要我列出詳細的變更清單嗎？
```

### 場景 6：待確認項目處理（25 秒）

**使用者輸入：**
```
「待分類」裡的 3 個檔案是什麼？讓我看看
```

**Claude 回應：**
```
待分類的 3 個檔案：

1. 「vocabulary-list.xlsx」
   → 單字表，但沒標年級。內容看起來是國中程度。
   建議：放到 grammar/ 並命名為「國中-核心單字表.xlsx」

2. 「homework-template.docx」
   → 作業模板，通用格式，不限年級。
   建議：放到根目錄或新建「templates/」資料夾

3. 「notes-20230915.txt」
   → 你的備課筆記，內容是第五課教學重點。
   建議：放到 slides/ 或新建「notes/」資料夾
```

**旁白：**
「連待分類的檔案，Claude 也幫你分析了內容並給出建議。你只要說『照你的建議處理』就好。」

### 場景 7：收尾（20 秒）

**旁白：**
「今天的重點是什麼？Claude 不只是一個會搬檔案的工具。它在整理的過程中會主動發現問題——重複的檔案、同名但不同內容的文件、無法分類的講義——然後一一回報給你。這就像有一個認真的助教幫你整理辦公室，整理完還附上一份報告。」

## 💡 延伸練習

### 練習 1：整理你的教材
用同樣的方法整理你自己的教材資料夾，讓 Claude 掃描並提出整理計畫。

### 練習 2：建立命名規範
讓 Claude 幫你制定一套教材命名規範（例如：年級-學期-主題-類型.副檔名），並套用到現有檔案。

### 練習 3：定期整理
每學期結束時，讓 Claude 掃描一次教材資料夾，找出新增的檔案、可能的重複、以及需要歸檔的舊資料。

## 🎯 學習目標檢查

完成這一課後，你應該能夠：
- [ ] 讓 Claude 掃描資料夾並制定整理計畫

- [ ] 用自然語言指導 AI 處理模糊的分類決策
- [ ] 在整理前先確認 AI 的計畫，避免誤刪重要檔案
