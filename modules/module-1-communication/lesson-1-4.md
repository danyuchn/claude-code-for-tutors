# 課程 1-4：主動介入與即時調整

學習在 AI 執行過程中隨時介入、調整方向——對話是雙向的！

## 📋 課程資訊
- **適合對象**：完成課程 1-3 的學員
- **所需時間**：10 分鐘
- **學習重點**：
  - 了解可以隨時打斷或調整 AI 的方向
  - 學習用自然語言描述你要的「感覺」
  - 透過多輪對話逐步調整到理想結果
- **工具需求**：Claude Code
- **本課產出**：三個不同語氣版本的家長調課通知信

---

## 🎬 拍攝腳本

### 場景 1：情境設定（25 秒）

**畫面：**
林老師需要發一封調課通知給家長

**旁白：**
「下週三的英文課臨時要改到週四，林老師需要發一封家長通知信。她下達了指令，得到了一封信——但看了一眼，覺得哪裡不對勁。」

---

### 場景 2：第一版——太正式（40 秒）

**使用者輸入：**
```
幫我寫一封通知信，告訴家長下週三的英文課改到週四同一時間
```

**Claude 回應（示意）：**
```
敬愛的家長，

謹此通知，由於課程安排調整，原定於下週三（X 月 X 日）
上午 10:00 舉行之英文課程，將移至下週四（X 月 X 日）
同一時間進行。

請各位家長知悉並安排出席。如有任何疑問，歡迎與本校聯繫。

林欣怡老師
```

**旁白：**
「信的內容是正確的，但語氣有點太正式了——像是學校的官方公文，而不像林老師平常的說話風格。她要怎麼調整？」

**字幕：**
```
💡 關鍵認知：不滿意就說！
你可以用自然語言告訴 Claude 你要什麼感覺
```

---

### 場景 3：介入！調整語氣（40 秒）

**使用者輸入：**
```
語氣太正式了，改成比較溫和、像朋友說話的感覺
```

**Claude 回應（示意）：**
```
各位家長好，

想跟大家說一聲，下週三的英文課因為場地臨時有狀況，
我們改到下週四同一時間上喔！

時間地點都不變，只是換個星期幾。如果有任何問題歡迎問我！

謝謝大家的配合 🙂

林老師
```

**旁白：**
「好多了！溫和、親切，有林老師的個人風格。但林老師覺得……還可以再微調一下。」

---

### 場景 4：再次介入！精細調整（40 秒）

**使用者輸入：**
```
這樣好多了！但開頭加上感謝家長配合的句子，
結尾改成林欣怡老師的完整署名，不要只寫「林老師」
```

**Claude 回應（示意）：**
```
各位親愛的家長好，

感謝大家一直以來對明日學院的支持與配合！

想提醒大家，下週三的英文課因為場地臨時有狀況，
我們改到下週四同一時間上喔！時間地點完全相同。

如果有任何問題，歡迎隨時找我！

林欣怡老師
```

**旁白：**
「這才是林老師想要的版本！透過兩次調整，從官方公文到有溫度的老師信件。整個過程只花了 3 分鐘。」

---

### 場景 5：三版本對比與總結（30 秒）

**畫面：**
三個版本並排顯示

**旁白：**
「你剛才看到了三個版本：正式版、溫和版、完美版。每一次調整，只需要用自然語言告訴 Claude 你要改什麼。就像你告訴設計師『顏色太重了、字體改小一點』一樣簡單。」

**字幕：**
```
記住：AI 不會因為你說「不對，再來一次」而生氣
對話是雙向的，可以一直調整直到滿意！
```

---

## 💡 延伸練習

### 練習 1：語氣調整挑戰
請 Claude 幫你寫一封家長信，然後試試看以下三種調整：
- 「改成更正式的語氣」
- 「改成更輕鬆，像發 LINE 訊息的感覺」
- 「加入一個具體的例子，讓家長更容易理解」

### 練習 2：你的個人風格
試著描述你自己的說話風格給 Claude：「我說話比較直接、不喜歡客套話，但很有親和力。」然後讓它生成一封符合你風格的信。

### 練習 3：介入練習
請 Claude 生成一份學生作業說明，在它生成的過程中，試著打斷它說：「等一下，幫我加入截止日期」。

---

## 📖 常見問題

### Q：我要調整幾次才算正常？
A：沒有固定次數！通常 2-3 次就能達到理想結果。但如果發現調整 5-6 次還差很多，可能需要重新寫一個更完整的指令。

### Q：我可以要求 Claude 一次生成多個版本讓我選嗎？
A：完全可以！試試：「請同時生成正式版和輕鬆版，讓我選擇」。

## 🎯 學習目標檢查

- [ ] 用自然語言描述你要的「感覺」或「風格」
- [ ] 透過 2-3 次調整得到滿意的結果
- [ ] 生成三個不同語氣版本的家長通知信
