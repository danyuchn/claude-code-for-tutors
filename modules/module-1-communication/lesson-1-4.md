# 課程 1-4：主動介入與即時調整

學習觀察 AI 是否真的在執行，以及卡住時如何用自然語言把它拉回來。

## 課程來源

- **改編自**：`claude-course/lessons/module-02-basic-collaboration/module-02-content-management-10.md` 場景 5（AI 執行停滯，使用者主動介入）
- **核心 AI 行為**：AI 不斷顯示「處理中」但沒有實際輸出，使用者用非技術性語言（「你還沒開始啊」）介入後，AI 立即切換策略直接產出
- **驚喜時刻**：老師只需要說「你還沒開始啊」（非技術指令），小艾就能理解意思並立刻切換執行策略

## 📋 課程資訊
- **適合對象**：完成課程 1-3 的學員
- **所需時間**：10 分鐘
- **學習重點**：
  - 如何觀察 AI 是否真的在執行（vs 一直說「處理中」）
  - 什麼時候該介入：卡住、輸出不符預期
  - 介入的語言不需要技術性——「直接寫」「跳過這個」「換個方式」就夠了
- **工具需求**：Claude Code
- **本課產出**：20 封個人化家長回覆

## 🎬 拍攝腳本

### 場景 1：情境設定（30 秒）

**畫面：**
林老師的螢幕上有一份家長問卷調查結果（20 位家長），旁邊是學生花名冊

**旁白：**
「學期末家長問卷回來了，20 位家長都寫了對孩子學習的回饋。林老師要針對每位家長寫一封個人化的回覆，提到他們孩子的具體進步。一封一封寫？太花時間了。她決定用上一課學到的長計畫，一次搞定。」

---

### 場景 2：給出長計畫（45 秒）

**畫面：**
林老師用上一課學到的方法，貼入完整計畫

**使用者輸入：**
```
請按照以下計畫執行：

## 背景
學期末家長問卷已回收，需要為每位家長寫個人化回覆信。

## 資料來源
以下是 20 位家長的問卷摘要和學生資料：
（貼入 parent-survey 和 student-roster 資料）

## 任務
為每位家長寫一封 80-120 字的個人化回覆，包含：
- 感謝家長填寫問卷
- 提到該學生本學期的一個具體進步點
- 回應家長問卷中提出的關切（如果有的話）

## 規範
- 語氣溫暖親切
- 署名「林欣怡老師」
- 請依照學生座號順序生成
```

**旁白：**
「林老師用了上一課的技巧——背景、資料、任務、規範，一次說清楚。」

---

### 場景 3：AI 開始「處理」——但沒有輸出（40 秒）

**畫面：**
Claude 的回應一直在「讀取資料」和「處理中」，但沒有實際的信件內容出現

**Claude 回應：**
```
我理解了。讓我先讀取資料並整理。

[Tool: Read] parent-survey.csv
[Tool: Read] student-roster.csv

正在交叉比對家長問卷和學生資料...
正在為每位家長生成個人化回覆...
處理中，請稍候...
```

**旁白：**
「注意看——Claude 說它在『處理中』，但螢幕上沒有出現任何一封信。它一直在讀取資料、一直在『準備』，卻沒有真正開始寫。這種情況你可能也遇過：AI 告訴你它正在做，但其實什麼都還沒做出來。」

**字幕：**
```
觀察重點：
AI 說「處理中」≠ AI 真的在做
要看有沒有「實際內容」出現
```

---

### 場景 4：主動介入——用自然語言拉回來（50 秒）

**畫面：**
林老師皺眉，打了一句很口語的話

**使用者輸入：**
```
你還沒開始寫啊，現在直接寫。
```

**Claude 回應：**
```
明白了，我直接開始：

【1 號 王小明家長】
親愛的王爸爸、王媽媽：

感謝您填寫本學期的學習問卷！小明這學期在閱讀理解上有明顯進步，
特別是英文故事書的讀後心得越寫越有自己的想法。
您提到希望加強口語練習，下學期我會在課堂上多安排對話活動。

林欣怡老師

【2 號 陳美玲家長】
親愛的陳媽媽：

感謝您用心填寫問卷！美玲本學期口語表達越來越有自信，
上課主動舉手發言的次數比上學期多了很多。
您建議增加寫作練習，我完全同意，下學期會加入更多英文日記活動。

林欣怡老師

【3 號 張家豪家長】
...
```
（繼續依序生成）

**旁白：**
「林老師只說了一句『你還沒開始寫啊，現在直接寫』——完全不是什麼技術指令，就是很自然的催促——Claude 馬上就懂了，立刻開始一封接一封地寫。這就是今天最重要的概念：你不需要懂技術，用你平常說話的方式就能指揮 AI。」

---

### 場景 5：驚喜時刻——非技術語言一樣有效（30 秒）

**畫面：**
畫面上列出幾個「介入語言」的對比

**旁白：**
「你不需要學什麼特別的語法。看看這些例子：」

**字幕：**
```
你平常怎麼說，就怎麼跟 AI 說：

「你還沒開始啊」     → AI 立刻開始
「跳過這個步驟」     → AI 略過不做
「不要用表格，用條列」→ AI 換格式
「太長了，簡短一點」  → AI 精簡內容
「換個方式試試」     → AI 改變策略
```

---

### 場景 6：第二次介入——調整方向（45 秒）

**畫面：**
林老師看到幾封信之後，發現某些回覆可以更好

**使用者輸入：**
```
等一下，第 5 號的家長在問卷裡有提到擔心孩子跟不上進度，
你的回覆太輕描淡寫了。針對有焦慮的家長，要多寫幾句安撫，
並給出具體的下學期改善計畫。
```

**Claude 回應：**
```
了解！我重新調整第 5 號的回覆，並在後續遇到家長表達焦慮時，
也採用同樣的安撫 + 具體計畫的寫法：

【5 號 黃雅婷家長】（修改版）
親愛的黃媽媽：

感謝您坦誠分享您的擔心，我非常理解您的心情。
雅婷這學期雖然在英文閱讀上需要多一點時間，
但她的學習態度一直很認真，這是最重要的基礎。

下學期我有三個具體計畫來幫助雅婷：
1. 每週一次課後 15 分鐘的個別閱讀指導
2. 搭配她程度的分級讀物，建立信心
3. 每月和您更新一次雅婷的學習進度

請放心，我們會一起陪雅婷進步的。

林欣怡老師
```

**旁白：**
「林老師在 AI 執行過程中隨時介入調整——不只是催它動手，還能改變策略。『針對焦慮的家長多寫幾句安撫』，Claude 立刻調整，而且後面的信也會自動套用新的寫法。」

---

### 場景 7：什麼時候該介入？（30 秒）

**旁白：**
「那要怎麼判斷什麼時候該介入呢？記住三個時機：」

**字幕：**
```
什麼時候該介入：
1. 卡住了：說「處理中」超過 30 秒卻沒有內容出現
2. 方向不對：輸出的內容不符合你的預期
3. 想加條件：執行到一半想到新的要求

介入方式：用你平常說話的方式就好
```

## 💡 延伸練習

### 練習 1：觀察與介入
請 Claude 幫你做一件需要多步驟的事（例如：批改 5 份作文）。過程中，練習觀察它的進度，如果卡住了就用自然語言催它。

### 練習 2：中途改方向
請 Claude 生成一系列學生評語，在看到第三個之後，中途加入新條件：「後面的每個評語都要提到該學生的一個具體優點」。

### 練習 3：連續調整
請 Claude 生成一份教案，然後連續做三次調整：
- 第一次：「時間太長了，壓縮到 40 分鐘」
- 第二次：「加入一個小組討論環節」
- 第三次：「把難度降低，適合程度比較弱的學生」

## 📖 常見問題

### Q：一直打斷 AI 會不會搞亂它？
A：不會！Claude 的每一次回覆都會考慮你說過的所有話。你的介入是在幫它更精準地完成任務，不是在搗亂。

### Q：如果介入之後結果更差了怎麼辦？
A：直接說：「剛才的版本比較好，回到之前的寫法」。Claude 記得前面的對話，可以回到你滿意的版本。

### Q：AI 卡住是常見的嗎？
A：偶爾會發生，特別是任務比較複雜的時候。重要的是你知道怎麼處理——不需要緊張，說一句「直接開始」就好。
