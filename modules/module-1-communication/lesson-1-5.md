# 課程 1-5：當 AI 問你問題

學習把 AI 的提問當成好事——它不是在刁難你，是在幫你找到最好的路！

## 課程資訊
- **適合對象**：完成課程 1-4 的學員
- **所需時間**：10 分鐘
- **學習重點**：
  - AI 問問題不是在刁難，是在找最好的解法
  - AI 問問題時，通常已經想好幾條出路
  - 「拒絕」往往是「換個方式」的前奏
  - 學會回答 AI 的問題（選擇最方便的那條路）
- **工具需求**：Claude Code
- **本課產出**：家長滿意度分析報告（找出需要主動聯繫的家長）

---

## 拍攝腳本

### 場景 1：情境設定（25 秒）

**畫面：**
林老師學期中想了解家長對她的評價，但她不知道從何下手

**旁白：**
「學期進行到一半，林老師隱約覺得有幾位家長好像對她不太滿意，但又說不清楚是哪些人、哪些事。她想請 Claude 幫忙分析——但問題是，她的家長對話記錄在 LINE 上，要怎麼給 AI？」

---

### 場景 2：下達任務，AI 無法直接執行（50 秒）

**使用者輸入：**
```
幫我根據我的LINE對話記錄，分析哪些家長對我最不滿意
```

**Claude 回應：**
```
我沒辦法直接存取你的 LINE 對話記錄。不過如果你能提供以下任一資料，
我就能幫你分析家長滿意度：

1. LINE 對話截圖——直接貼到這裡，我可以讀取圖片內容
2. 家長問卷結果（.csv 或 .xlsx）——我看到 horizon-academy 資料夾裡
   已經有一份 parent-survey.csv，要不要我先看看？
3. 你覺得有問題的幾則對話，直接貼文字給我

哪種方式對你比較方便？
```

**旁白：**
「注意看！Claude 並沒有說『我做不到，掰掰』。它做了三件事：第一，說明為什麼不能直接做；第二，給出三條替代路線；第三，其中一條路——問卷資料——甚至已經在專案裡了！林老師根本不需要做任何額外準備。」

**字幕：**
```
AI 的「拒絕」= 三條出路
其中一條可能已經幫你準備好了！
```

---

### 場景 3：選擇最方便的路（40 秒）

**旁白：**
「面對三個選項，林老師只需要選最方便的那個。她不需要去截圖、不需要翻對話，因為問卷資料就在手邊。」

**使用者輸入：**
```
我用問卷好了，你幫我看那個 parent-survey.csv
```

**Claude 回應：**
```
[Tool: Read] horizon-academy/parent-survey.csv

我讀到了 20 位家長的問卷回覆。讓我同時讀取學生成績資料來做交叉分析。

[Tool: Read] horizon-academy/exam-scores.csv
```

**旁白：**
「Claude 不只讀了問卷，還主動去讀了成績資料——它想要交叉比對，讓分析更有深度。這就是 AI 在回答你之前，已經在幫你想下一步了。」

**字幕：**
```
驚喜時刻：
資料早就在專案裡，老師不需要做任何準備
AI 還主動讀取額外資料做交叉分析
```

---

### 場景 4：分析結果出爐（60 秒）

**Claude 回應（示意）：**
```
根據問卷和成績資料的交叉分析，以下是家長滿意度報告：

## 需要優先聯繫的家長（滿意度偏低）

1. 張志豪家長（整體 2 分）
   - 擔心教學方式不適合孩子
   - 成績確實有下降趨勢：63 → 60 → 55
   - 建議：主動約面談，討論個別化學習方案

2. 蘇冠廷家長（整體 2 分）
   - 孩子反映聽不懂，希望多用中文解釋
   - 成績偏低但有起伏：52 → 48 → 55
   - 建議：調整教學節奏，增加中文輔助說明

## 需要關注的家長（有具體建議）

3. 林大偉家長（整體 3 分）
   - 反映上課速度快，跟不上
   - 成績緩慢進步中：55 → 58 → 62
   - 建議：肯定進步趨勢，同時說明會注意節奏

## 已滿意但有改善空間

4. 賴政翰家長（整體 4 分，但溝通效率 3 分）
   - 回覆 LINE 訊息太慢
   - 建議：設定每日固定回覆時段

5. 王小明家長（整體 4 分，但溝通效率 3 分）
   - 同樣希望更快回覆訊息
   - 好消息：孩子成績持續進步 72 → 85 → 88
```

**旁白：**
「看到了嗎？Claude 不只列出誰不滿意，還交叉比對了成績趨勢，給出具體的聯繫建議。張志豪成績真的在掉，所以家長的擔心有道理；蘇冠廷成績偏低但最近回升了，所以老師可以帶著好消息去溝通。」

---

### 場景 5：追問更多細節（30 秒）

**使用者輸入：**
```
幫我列出需要在這週內主動聯繫的家長清單，
依照緊急程度排序，還有每位建議的溝通重點
```

**旁白：**
「拿到初步分析後，林老師可以繼續追問。AI 已經掌握了所有資料，接下來的對話會越來越精準。就像跟一個已經看過所有資料的助理討論下一步。」

---

### 場景 6：回顧整個過程（30 秒）

**旁白：**
「讓我們回顧一下剛才發生了什麼。林老師說了一句『分析我的 LINE 對話』，Claude 做不到——但它沒有停在那裡。它給了三條路，其中一條根本不需要林老師額外準備。選好路之後，AI 還主動去讀額外資料來加強分析。」

**字幕：**
```
當 AI 問你問題時：
1. 它不是在刁難你，是在幫你找最好的路
2. 通常它已經想好幾條出路了
3. 選最方便的那條就好
4. AI 的「拒絕」往往是「換個更好的方式」
```

---

### 場景 7：與課程 1-4 的連結（20 秒）

**旁白：**
「還記得上一課學的嗎？不滿意就說。這一課更進一步：當 AI 問你問題，也直接選一個答案。AI 的問題不是考試題，沒有標準答案——選你覺得最方便的就對了。」

## 延伸練習

### 練習 1：故意讓 AI 問問題
給 Claude 一個模糊的指令，例如「幫我整理學生資料」，看看它會問你什麼問題。練習從它的問題中找到最方便的路。

### 練習 2：選擇替代方案
當 AI 說「我沒辦法直接做 X」時，注意看它提供的替代方案。試試不同的選項，比較結果差異。

### 練習 3：用你的真實資料試試
把你班上的問卷或成績資料（去除敏感資訊後）給 Claude，請它幫你分析哪些家長需要主動關心。

## 常見問題

### Q：AI 問問題的時候，我可以不回答某些問題嗎？
A：可以！直接說「這個我還不確定，先跳過」。AI 會根據你回答的部分先做分析，有需要再補問。

### Q：如果三個替代方案我都做不到怎麼辦？
A：直接告訴 AI：「這三個方法都不方便，有沒有其他做法？」它通常能再想出新的方案。

### Q：AI 可以分析圖片嗎？真的可以截圖給它？
A：可以！Claude Code 能讀取圖片內容。把 LINE 對話截圖直接貼進去，它就能分析文字內容。
