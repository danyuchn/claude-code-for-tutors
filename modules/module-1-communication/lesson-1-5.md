# 課程 1-5：當 AI 問你問題

學習把 AI 的提問當成好事——它是在幫你把任務想得更清楚！

## 📋 課程資訊
- **適合對象**：完成課程 1-4 的學員
- **所需時間**：8 分鐘
- **學習重點**：
  - 理解 AI 主動提問是在協助澄清需求
  - 學會提供具體、有數字的回答
  - 了解如何引導 AI 做出好的決策
- **工具需求**：Claude Code
- **本課產出**：下學期英文課課表草稿

---

## 🎬 拍攝腳本

### 場景 1：情境設定（25 秒）

**畫面：**
林老師需要排下學期課表，有點頭痛

**旁白：**
「下學期課表是每個學期初最讓林老師頭痛的任務之一。需要考慮班級數量、教室、時段……還有老師自己的時間。今天她要讓 Claude 幫忙，看看會發生什麼。」

---

### 場景 2：下達任務，Claude 問問題（50 秒）

**使用者輸入：**
```
幫我排下學期的英文課課表
```

**Claude 回應：**
```
我很樂意幫您規劃英文課課表！在開始之前，我需要了解一些資訊：

1. 您有幾個英文班級？每班幾位學生？
2. 每班每週上幾節英文課？每節課多長？
3. 英文課是由您一個人教，還是有其他英文老師？
4. 有特定的教室限制嗎？（例如：某個教室有特殊設備）
5. 有固定不能排課的時段嗎？（例如：固定會議、備課時間）
6. 學校上課時間是幾點到幾點？
```

**旁白：**
「Claude 問了 6 個問題。這是 Claude 在認真工作的表現！一個好的課表排法，真的需要這些資訊。如果少了任何一個，排出來的課表可能完全無法使用。」

**字幕：**
```
💡 AI 問問題 ≠ AI 不聰明
= AI 在幫你把任務想清楚！
```

---

### 場景 3：如何回答 AI 的問題（50 秒）

**旁白：**
「林老師要怎麼回答這些問題？關鍵是：具體、有數字、不含糊。」

**字幕：**
```
❌ 模糊回答：「幾個班，排完再說」
✅ 具體回答：「3 個班，每班 25 人」
```

**使用者輸入：**
```
以下是我的答案：
1. 3 個班（A班、B班、C班），每班 25 位學生
2. 每班每週 3 節，每節 50 分鐘
3. 只有我一位英文老師
4. 需要在有音響設備的教室（多媒體教室 M101 或 M102）
5. 週三下午 3:00 之後有教師會議，週五下午全天是學校開放日
6. 學校上課時間：週一到週五 8:00-17:00（共 9 節，每節 50 分鐘）
```

---

### 場景 4：課表結果（40 秒）

**Claude 回應（示意）：**
```
根據您的條件，以下是建議的課表草稿：

| 時段 | 週一 | 週二 | 週三 | 週四 | 週五 |
|------|------|------|------|------|------|
| 第 1 節 8:00 | A班 (M101) | | | B班 (M101) | |
| 第 2 節 9:00 | | C班 (M102) | A班 (M101) | | |
| 第 3 節 10:00 | | | | | C班 (M101) |
| 第 4 節 11:00 | B班 (M102) | | | | |
| ...（其餘時段）

特別安排說明：
- 週三下午和週五下午已空出（符合您的限制）
- A班、B班、C班各有 3 節課
- 每節課都安排在多媒體教室

如果有需要調整的部分，請告訴我！
```

**旁白：**
「Claude 根據 6 個條件，生成了一份符合所有限制的課表草稿。如果林老師只說了『幫我排課表』，根本不可能得到這個結果。」

---

### 場景 5：小調整（20 秒）

**使用者輸入：**
```
A班的週一第 1 節太早，可以改到第 3 節嗎？
```

**旁白：**
「拿到草稿後，可以繼續微調。這個課表的建立，是林老師和 Claude 共同完成的——林老師提供資訊和判斷，Claude 做整理和計算。」

---

### 場景 6：總結（20 秒）

**字幕：**
```
當 AI 問你問題時：
✅ 把它當成澄清的機會
✅ 回答要具體、有數字
✅ 不確定的可以說「先假設 X，之後再調整」
```

---

## 💡 延伸練習

### 練習 1：主動引發問題
試著下一個不完整的指令，故意讓 Claude 問你問題，然後練習回答。

### 練習 2：提前預想問題
下一個複雜指令之前，先想想「Claude 可能會問我什麼」，把答案都寫進去。

### 練習 3：排你的課表
用今天學到的方法，請 Claude 幫你排本週的課程或工作計畫。

---

## 📖 常見問題

### Q：如果我不知道某個問題的答案怎麼辦？
A：直接告訴 Claude：「這個我還不確定，先假設 X，做完之後如果要調整告訴我。」AI 可以根據假設值先做，之後修改很簡單。

### Q：Claude 可以一次問完所有問題，不要分批問嗎？
A：可以在指令裡說：「如果你有問題，請一次列出所有問題，不要一個一個問。」這樣可以加快溝通速度。

- [ ] 用 Claude 生成符合實際限制的課表草稿
