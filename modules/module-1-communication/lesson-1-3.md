# 課程 1-3：長計畫 vs. 短指令

學習什麼時候需要一次給完整背景，讓 Claude 真正理解複雜任務。

## 📋 課程資訊
- **適合對象**：完成課程 1-2 的學員
- **所需時間**：12 分鐘
- **學習重點**：
  - 區分「簡單任務」和「需要背景的複雜任務」
  - 學會在指令開頭提供完整的任務背景
  - 練習「一次說清楚」的計畫式指令
- **工具需求**：Claude Code
- **本課產出**：明日學院家長說明會完整議程（2 小時）

---

## 🎬 拍攝腳本

### 場景 1：情境設定（30 秒）

**畫面：**
林老師的桌上有一張便條紙寫著「家長說明會 - 下週四 - 需要議程」

**旁白：**
「林老師下週要辦一場家長說明會，主任交代她要負責規劃完整議程。這是一個複雜任務，需要考慮很多因素。她要怎麼讓 Claude 幫上忙？」

---

### 場景 2：短指令的嘗試（45 秒）

**使用者輸入：**
```
幫我規劃家長說明會的議程
```

**Claude 回應：**
```
好的！請提供以下資訊，我才能幫您設計合適的議程：

1. 說明會的時間長度是多少？
2. 預計有多少家長參加？
3. 說明會的主要目的是什麼？
4. 有哪些主題需要涵蓋？
5. 是否需要互動環節？
...
```

**旁白：**
「Claude 又問了一堆問題——這次有 5 個！這不是 Claude 不聰明，而是『規劃議程』這件事本身就需要很多背景資訊。試想：如果你請一位同事幫你規劃議程，她也會問同樣的問題。」

**字幕：**
```
複雜任務 ≠ 簡單指令
任務越複雜，開頭要說越多！
```

---

### 場景 3：什麼情況需要「長計畫」？（30 秒）

**旁白：**
「怎麼判斷要給短指令還是長計畫呢？一個簡單的原則：如果任務有多個條件、多個限制、多個目的，就先把這些都說清楚再開始。」

**字幕：**
```
需要長計畫的情況：
✅ 有時間限制（2 小時、下週五之前）
✅ 有對象限制（家長、高中生、成人）
✅ 有多個目的（介紹課程＋說明費用＋收集意見）
✅ 有特殊要求（不要太正式、要有互動）
```

---

### 場景 4：長計畫版本示範（70 秒）

**畫面：**
林老師一次輸入完整背景

**使用者輸入：**
```
請幫我規劃明日學院的家長說明會議程，以下是完整背景：

【基本資訊】
- 時間：下週四下午 2:00-4:00（共 2 小時）
- 地點：明日學院多功能廳（可容納 60 人）
- 預計出席：約 50 位家長

【說明會目的】
1. 介紹下學期英文分班考試辦法（最重要！）
2. 說明新的個人化課程架構
3. 收集家長對課程的建議

【特殊要求】
- 開頭不要太嚴肅，要讓家長輕鬆進入狀況
- 保留至少 20 分鐘讓家長自由提問
- 結束前要有一個讓家長能帶回家的具體資料

請設計一個分時段的完整議程，包含每個環節的時間和負責人建議。
```

**Claude 回應（示意）：**
```
明日學院家長說明會議程
時間：下週四 14:00-16:00

14:00-14:10｜暖場與歡迎
- 輕鬆的開場，介紹出席老師
- 破冰小活動：請家長說說孩子最近的英文學習狀況

14:10-14:40｜英文分班考試說明（核心重點）
- 考試時間、範圍、計分方式
- 分班後的課程規劃差異
- Q&A（5 分鐘）

14:40-15:00｜新學期課程架構介紹
- 個人化學習計畫說明
- 家長如何追蹤孩子進度

15:00-15:30｜家長自由提問時間
- 開放問答，林老師主持

15:30-15:45｜意見收集
- 填寫家長建議表單

15:45-16:00｜結束與資料發放
- 發放「分班考試準備指南」（帶回家的資料）
- 感謝家長出席

【建議帶回家的資料】
- 分班考試準備指南（一頁）
- 明學期課程架構說明
```

**旁白：**
「這次 Claude 一次就給出了完整的分時段議程，甚至還建議了帶回家的資料。這就是『長計畫』的威力！」

---

### 場景 5：比較與總結（30 秒）

**旁白：**
「記住這個規則：簡單任務用短指令，複雜任務先說背景。任務開頭多花 2 分鐘把背景說清楚，可以省下後面 10 分鐘的來回溝通。」

**字幕：**
```
短指令：適合簡單、清晰的單一任務
長計畫：適合有多個條件的複雜任務
規則：開頭多說，後面省事
```

## 💡 延伸練習

### 練習 1：把短指令升級
試著把以下短指令改成完整的長計畫版本：
- 「幫我寫一封家長通知信」
- 「幫我設計一份英文月考」
- 「幫我規劃下學期的課程」

### 練習 2：實際規劃一場會議
想一場你近期要辦的會議或活動，用完整背景的方式請 Claude 幫你設計議程。

### 練習 3：「計畫模板」練習
請 Claude 幫你建立一個「家長說明會議程模板」，以後每學期可以直接填入細節使用。

---

## 📖 常見問題

### Q：指令多長才算夠？
A：沒有固定長度，重點是把「Claude 做決定需要的資訊」都提供完整。如果你覺得 Claude 可能會問什麼問題，就先把答案寫進去。

### Q：如果我忘記說某個條件怎麼辦？
A：沒關係！拿到初版結果後，繼續補充：「請在 14:00-14:10 的環節加入簡短的自我介紹」。AI 的對話是可以一直接著說的。
