# 課程 1-3：長計畫 vs. 短指令

學習什麼時候該把完整計畫一次給 AI，讓它直接執行，不需要來回問答。

## 課程資訊
- **適合對象**：完成課程 1-2 的學員
- **所需時間**：12 分鐘
- **學習重點**：
  - 區分「簡單任務用短指令」和「複雜任務用長計畫」
  - 體驗長計畫的威力：一次說清楚，AI 直接動手
  - 學會寫一份 AI 能理解的執行計畫（背景、步驟、條件、驗收標準）
- **工具需求**：Claude Code
- **本課產出**：三版不同語氣的家長說明會通知信模板

---

## 拍攝腳本

### 場景 1：情境設定（30 秒）

**畫面：**
林老師的桌上有一疊資料：「學期末家長說明會」企劃書，旁邊是三個班級的學生名單

**旁白：**
「學期末到了，林老師要發家長說明會通知信。問題是：低年級、高年級、國中部的家長，語氣要完全不同。這不是一封信的事——是三封。而且每封信的規則都不一樣。她要怎麼讓 AI 一次搞定？」

---

### 場景 2：短指令的嘗試（45 秒）

**使用者輸入：**
```
幫我寫家長說明會的通知信
```

**Claude 回應：**
```
好的！請提供以下資訊，我才能幫您設計合適的通知信：

1. 說明會的時間和地點？
2. 通知的對象是哪些家長？
3. 說明會的主要內容是什麼？
4. 語氣要正式還是親切？
5. 需要家長回覆或報名嗎？
...
```

**旁白：**
「又來了——Claude 問了一堆問題。但這次不是 Claude 笨，而是『寫三種不同語氣的通知信』本來就需要很多條件。就像你請同事幫忙，他也得先問清楚。那有沒有辦法一次說完？」

**字幕：**
```
複雜任務 ≠ 簡單指令
條件越多，開頭要說越多
```

---

### 場景 3：什麼時候需要「長計畫」？（30 秒）

**旁白：**
「怎麼判斷要給短指令還是長計畫？簡單的原則：如果你的任務有多個對象、多種條件、多個步驟，就先把這些都寫清楚再開始。」

**字幕：**
```
需要長計畫的情況：
- 有多個對象（低年級、高年級、國中部）
- 每個對象有不同條件（語氣、格式、內容）
- 有特殊規範（必填欄位、格式要求）
- 需要批次產出（一次生成多份）
```

---

### 場景 4：長計畫版本——一次貼入（90 秒）

**畫面：**
林老師一次輸入完整的執行計畫

**使用者輸入：**
```
請按照以下計畫執行：

# 學期末家長說明會通知信實施計畫

## 背景
明日學院學期末家長說明會將於 1/15（六）下午 2:00-4:00 舉行。
需要通知三個學生群組的家長，每組語氣和重點不同。

## 三個群組分類
1. 低年級（1-3 年級）：活潑親切語氣，用「爸爸媽媽」稱呼，強調孩子的成長和趣味活動
2. 高年級（4-6 年級）：溫和正式語氣，用「家長」稱呼，強調學習成果和升學銜接
3. 國中部（7-9 年級）：學術專業語氣，用「家長」稱呼，強調會考準備和個人學習計畫

## 每封信必須包含
- 說明會時間地點
- 該群組的重點議程（各不同）
- 需要家長事前準備的事項
- 回條（確認出席 / 線上參與 / 無法出席）

## 格式規範
- 每封信 300-400 字
- 開頭有稱呼，結尾有署名「林欣怡老師」
- 不要用太多驚嘆號

請依序生成三個版本。
```

**Claude 回應（示意）：**
```
我理解了。根據計畫，我會按照步驟執行：

1. 為低年級家長（活潑親切語氣）生成通知信
2. 為高年級家長（溫和正式語氣）生成通知信
3. 為國中部家長（學術專業語氣）生成通知信

每封信都會包含：時間地點、群組專屬議程、家長準備事項、回條。

讓我開始。

---

【低年級版本】

親愛的爸爸媽媽：

這學期過得好快，孩子們在明日學院的每一天都讓我們很感動！
學期末家長說明會即將舉行，我們準備了好多成果要跟您分享...
```
（繼續依序生成三個版本）

**旁白：**
「注意看——林老師貼了 20 行的計畫書，Claude 完全理解，沒有問任何問題，直接確認步驟就開始寫了。三種語氣、三種稱呼、三組不同的議程重點，全部一次搞定。」

---

### 場景 5：驚喜時刻——AI 真的讀懂了（40 秒）

**畫面：**
三封信並排顯示，用螢光筆標出語氣差異

**旁白：**
「來看看三封信的差別：低年級版用了『爸爸媽媽』、提到『趣味活動』和『成長』；高年級版改成『家長』、提到『學習成果』和『升學銜接』；國中部版語氣最專業，聚焦在『會考準備』和『個人學習計畫』。每一封都精準對應了計畫書裡的條件。」

**字幕：**
```
長計畫的威力：
一次給完整條件 → AI 一次產出所有版本
不需要來回問答，不需要逐一修改
```

---

### 場景 6：長計畫的寫法公式（30 秒）

**旁白：**
「你剛才看到的長計畫，其實有一個簡單的結構：背景是什麼、要做什麼、每一份有什麼條件、有什麼格式規範。記住這四個部分，就能寫出 AI 看得懂的計畫書。」

**字幕：**
```
長計畫結構：
1. 背景（為什麼做）
2. 任務（做什麼）
3. 條件（每份的差異）
4. 規範（格式、長度、語氣）
```

---

### 場景 7：比較與總結（30 秒）

**旁白：**
「記住這個規則：簡單任務用短指令，複雜任務先寫計畫。開頭多花 3 分鐘把計畫寫清楚，可以省下後面 15 分鐘的來回溝通。」

**字幕：**
```
短指令：「幫我寫通知信」→ 被問 5 個問題
長計畫：一次給完所有條件 → 直接拿到成品
```

## 延伸練習

### 練習 1：把短指令升級成長計畫
試著把以下短指令改成完整的長計畫版本：
- 「幫我寫一封家長通知信」
- 「幫我設計一份英文月考」
- 「幫我規劃下學期的課程」

### 練習 2：用長計畫一次生成多版本
想一個需要多種版本的任務（例如：不同程度的學生作業、不同場合的演講稿），用長計畫的方式一次生成所有版本。

### 練習 3：建立你的計畫模板
請 Claude 幫你建立一個「家長通知信計畫模板」，以後每次要發通知信，只要填入細節就能用。

---

## 常見問題

### Q：計畫要寫多長才夠？
A：沒有固定長度，重點是把「Claude 做決定需要的資訊」都提供完整。如果你覺得 Claude 可能會問什麼問題，就先把答案寫進去。

### Q：如果我忘記說某個條件怎麼辦？
A：沒關係！拿到結果後，繼續補充就好：「國中部版本再加上段考成績分析的議程」。AI 的對話是可以一直接著說的。

### Q：長計畫會不會太長，AI 看不完？
A：不會。Claude 可以處理非常長的文字。20 行、50 行、甚至 100 行的計畫書都沒問題。寫多一點比寫不夠好。
