# 課程 1-2：給 AI 看，不只是說

學習直接把資料貼給 Claude，而不只是口頭描述，效果差距驚人。

## 📋 課程資訊
- **適合對象**：完成課程 1-1 的學員
- **所需時間**：10 分鐘
- **學習重點**：
  - 理解「直接給資料」比「描述資料」更有效
  - 學習把 LINE 訊息、Email、表格等複製貼入 Claude
  - 了解 Claude 可以讀取哪些格式的資料
- **工具需求**：Claude Code
- **本課產出**：家長訊息分類表 + 回覆草稿

---

## 🎬 拍攝腳本

### 場景 1：情境設定（30 秒）

**畫面：**
林老師的手機螢幕上有很多未讀的 LINE 家長訊息

**旁白：**
「林老師今天的手機有 23 則家長訊息。有的是詢問課程，有的是緊急狀況，有的是感謝。她需要判斷哪些要優先回覆，但光是看訊息就已經花了 10 分鐘。今天我們來試試更聰明的方法。」

---

### 場景 2：口頭描述的限制（45 秒）

**畫面：**
林老師嘗試描述家長訊息

**使用者輸入：**
```
我有一封家長訊息，說她的孩子下週要請假，問我怎麼補課，
幫我回覆她
```

**Claude 回應：**
```
您好，我很樂意幫您起草回覆。不過我需要了解一些資訊：
- 請假幾天？
- 是什麼原因請假？
- 您的補課政策是什麼？
- 這位學生的名字或班級？
```

**旁白：**
「Claude 又要問問題了。這次的問題是因為資訊不夠完整——它看不到原本的訊息，只能依賴你的描述。」

**字幕：**
```
問題：描述≠資料
解決方案：直接給 Claude 看原文！
```

---

### 場景 3：直接貼入效果（60 秒）

**畫面：**
林老師從手機截圖或複製訊息，貼到 Claude

**使用者輸入：**
```
以下是今天收到的三則家長訊息，請幫我：
1. 分類為「緊急」「一般詢問」「讚美/感謝」
2. 按重要性排序
3. 為每則訊息起草一個簡短回覆

=== 訊息 1（陳媽媽）===
老師，我家小孩下週要去醫院做例行檢查，會請假週二和週三，
請問這期間的課程進度怎麼安排比較好？

=== 訊息 2（王爸爸）===
老師！！！我孩子今天哭著回家說班上有同學一直嘲笑他的英文發音，
這個問題要馬上解決！！！我明天要來學校談！！

=== 訊息 3（李媽媽）===
謝謝老師這學期的用心，小美每天回家都很開心地跟我分享上課內容，
英文進步很多，真的非常感謝您！
```

**Claude 回應（示意）：**
```
分析結果：

| 分類 | 訊息來源 | 建議優先順序 |
|------|---------|------------|
| 🔴 緊急 | 王爸爸 | 立即回覆 |
| 🟡 一般詢問 | 陳媽媽 | 今天回覆 |
| 🟢 讚美 | 李媽媽 | 明天回覆也OK |

建議回覆草稿：

**王爸爸（緊急）：**
王爸爸您好，謝謝您第一時間告訴我這個情況。
我完全理解您的擔心，明天我會先觀察班上狀況，
也期待和您見面詳細討論。請問方便幾點來學校？

**陳媽媽（詢問）：**
陳媽媽您好，感謝告知。...
```

**旁白：**
「看到差別了嗎？林老師把三則訊息直接貼入，Claude 馬上就能分析、排序、起草回覆——完全不需要再問問題！」

---

### 場景 4：其他可以直接貼入的資料（30 秒）

**旁白：**
「除了 LINE 訊息，你還可以直接貼入什麼？」

**字幕依序顯示：**
```
✅ Email 內容
✅ 學生名單（Excel 複製貼上）
✅ 表格資料
✅ 考題或作文（讓 AI 批改建議）
✅ 課程大綱（讓 AI 幫忙優化）
✅ 家長問卷回覆
```

---

### 場景 5：總結（20 秒）

**旁白：**
「記住這個原則：能給資料就給資料，不要讓 AI 靠猜測！把資料直接貼入，省去來回溝通的時間，結果也更準確。」

**字幕：**
```
原則：能給原文就給原文
Claude 看得到，才能真正幫到你
```

## 💡 延伸練習

### 練習 1：貼入今天的家長訊息
把今天收到的 2-3 則家長訊息（可以匿名化）貼給 Claude，讓它分類並起草回覆。

### 練習 2：貼入你的學生名單
把一份學生名單（Excel）複製並貼入 Claude，問它「這份名單裡有幾位同學？哪些欄位資訊不完整？」

### 練習 3：貼入一份作業
把一位學生的英文作文（或作業）貼給 Claude，請它給出修改建議（不要直接改，只給方向）。

---

## 📖 常見問題

### Q：學生的個人資料可以貼給 AI 嗎？
A：練習時建議使用虛擬資料或匿名化（把名字改成代號）。真實個資的處理要符合學校的資訊安全政策。本課程的範例資料都是虛構的。

### Q：貼入的資料有長度限制嗎？
A：Claude 可以處理很長的文字，但如果資料太大（例如整個 Excel 的 1000 筆資料），可能需要分批處理。

### Q：貼入的 LINE 截圖，Claude 看得懂嗎？
A：可以！Claude 可以理解圖片裡的文字。但直接複製文字通常比截圖更準確，因為 AI 讀文字比讀圖片更精確。
