# 課程 1-2：給 AI 看，不只是說（截圖/貼文字）

直接把資料貼給 AI 或截圖給它看，它能發現你肉眼看不到的問題。

## 課程資訊
- **適合對象**：完成課程 1-1 的學員
- **所需時間**：12 分鐘
- **學習重點**：
  - 截圖/貼文字讓 AI 能「看」到你看到的東西
  - AI 從視覺資料中提取肉眼難以察覺的資訊（公式錯誤、數值異常）
  - 工具失敗不等於任務失敗，AI 會自動找替代方案
  - 「給 AI 看」比「跟 AI 說」更準確、更有效
- **工具需求**：Claude Code
- **本課產出**：成績表問題診斷報告

## 拍攝腳本

### 場景 1：開場情境（30 秒）

**畫面：**
林老師盯著電腦上的 Excel 成績表，眉頭微皺。她覺得有些數字怪怪的，但看了好幾遍都看不出來。

**旁白：**
「林老師剛整理完這學期的成績表，但心裡總覺得哪裡怪怪的。她已經盯著看了二十分鐘，數字密密麻麻的，越看越花。上一課我們學了用口語跟 AI 說話，今天要學更強的招數——直接把資料『給 AI 看』！」

**字幕：**
```
今天的任務：讓 AI 幫你「看」成績表，找出問題
上一課：用口語說 → 今天：直接給資料看
```

---

### 場景 2：口頭描述的局限（40 秒）

**畫面：**
林老師嘗試用說的方式描述成績表的問題

**使用者輸入：**
```
我的成績表好像有些地方不太對，有個學生的平均分算出來怪怪的
```

**Claude 回應：**
```
我可以幫你看看！不過我需要更多資訊：
- 是哪位學生？
- 平均分是多少？你覺得應該是多少？
- 成績表的格式是什麼？各科的分數分別是？
- 平均分是用什麼公式算的？
```

**旁白：**
「又來了！AI 問了一堆問題。因為它看不到成績表，只能靠猜。但如果你直接把成績表截圖給它看呢？」

**字幕：**
```
問題：你說的 vs AI 理解的 → 中間有落差
解法：直接截圖給 AI 看！
```

---

### 場景 3：截圖給 AI 看——驚喜時刻（90 秒）

**畫面：**
林老師把 Excel 成績表截圖貼給 Claude。Claude 仔細分析後回應。

**使用者輸入：**
```
（貼入成績表截圖）
你看這個哪裡怪怪的？
```

**Claude 回應：**
```
我仔細看了這份成績表，發現兩個問題：

問題 1：公式錯誤
S011 周俊傑的平均分有問題——
你的公式是 =SUM(C11:E11)/3，但第三次月考的 E 欄是空的。
Excel 把空格當成 0，所以 SUM 加了三個數字（78+72+0），
再除以 3，得到 50 分。
但實際上他只考了兩次，平均應該是 (78+72)/2 = 75 分。
→ 少算了 25 分！

問題 2：異常落差
S004 李佳穎的前兩次月考差距很大（87→52）。
這種 35 分的落差通常不是學習問題，可能是出席或情緒的變化。
建議跟班導師確認她第二次月考期間的狀況。

要我幫你修正周俊傑的平均分計算方式嗎？
我可以建議用 =AVERAGE(C11:E11) 取代 =SUM/3，
這個函數會自動跳過空格。
```

**旁白：**
「看到了嗎？林老師只說了一句『你看這個哪裡怪怪的』，然後貼了截圖。AI 立刻就找到兩個問題！第一個是公式錯誤——空格讓平均分少算了 25 分，這個錯誤林老師盯著看二十分鐘都沒發現。第二個是成績異常落差，AI 甚至建議了可能的原因。這就是『給 AI 看』的威力：它能從密密麻麻的數字中，找到你肉眼看不到的問題。」

**字幕：**
```
驚喜時刻：老師看 20 分鐘沒發現的錯誤，AI 一秒找到
公式錯誤：空格讓平均分少了 25 分
異常偵測：35 分落差 → 建議跟進
```

### 場景 4：工具失敗 → 自動切換方案（60 秒）

**畫面：**
林老師分享 Google Sheet 連結，AI 嘗試讀取失敗，自動切換方式

**使用者輸入：**
```
我的成績總表在這裡：（貼入 Google Sheet 連結）
幫我檢查所有學生的平均分有沒有類似的問題
```

**Claude 回應：**
```
我來讀取你的 Google Sheet...

[Tool: Sheets API 讀取]
失敗 — 這個檔案是上傳的 .xlsx，不是原生 Google Sheets，
   Sheets API 無法直接讀取。

沒關係，我換個方式！改用瀏覽器直接開啟：

[Tool: 瀏覽器開啟連結]
[Tool: 截圖讀取頁面]
成功 — 已讀取到完整的成績資料

掃描結果：在 35 位學生中，發現 3 筆平均分計算異常：
| 學生 | 問題 | 影響 |
|------|------|------|
| S011 周俊傑 | E 欄空格，SUM/3 公式錯誤 | 少算 25 分 |
| S023 黃雅婷 | D 欄數字後有隱藏空格 | 平均少 0.3 分 |
| S029 陳威廷 | 重複計算第一次月考 | 多算 5 分 |
```

**旁白：**
「這裡展示了另一個重要的觀念：工具失敗不等於任務失敗！AI 先試了 Google Sheets API，發現讀不了，它沒有停下來問你怎麼辦，而是自動切換到瀏覽器截圖的方式讀取。對林老師來說，她完全不需要知道背後發生了什麼技術問題——AI 自己想辦法搞定了。」

**字幕：**
```
關鍵學習點：工具失敗 ≠ 任務失敗
Sheets API 失敗 → 自動切換瀏覽器截圖
AI 自己找替代方案，你不需要操心
```

## 延伸練習

### 練習 1：截圖成績表
把你的成績表（或任何 Excel 表格）截圖給 AI，問它「有沒有哪裡怪怪的？」

### 練習 2：貼入家長訊息
把今天收到的 2-3 則家長訊息直接貼給 AI，讓它分類並起草回覆。

### 練習 3：貼入學生作文
貼入一篇學生的英文作文，請 AI 給出修改方向（不直接改，只給建議和優先順序）。

### 練習 4：比較效果
同一份資料，先用口頭描述試一次，再直接貼入試一次，比較兩次結果的差異。

## 常見問題

### Q：截圖 AI 真的看得懂嗎？
A：可以！AI 能理解圖片中的文字、數字、表格格式。但如果截圖太模糊或字太小，辨識率會下降。建議截圖時放大到看得清楚每個字的程度。

### Q：學生個資可以貼給 AI 嗎？
A：練習時建議使用虛擬資料或匿名化（把名字改成代號）。真實個資的處理要符合學校的資訊安全政策。本課程的範例資料都是虛構的。

### Q：很大的 Excel 表格怎麼辦？
A：如果資料太多，可以分批截圖或複製貼上重要的部分。也可以直接把檔案路徑告訴 AI，讓它用工具直接讀取整個檔案。

### Q：為什麼 AI 能發現我看不到的問題？
A：AI 逐一檢查每個數字、每個公式，不會因為「看了太久眼花」而漏掉。它特別擅長找出公式錯誤、數值異常、格式不一致這類系統性的問題。
