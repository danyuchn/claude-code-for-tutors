# 課程 1-1：用口語說清楚需求

學習如何用具體、精準的語言讓 Claude 真正理解你想要什麼。

## 📋 課程資訊
- **適合對象**：完成 Module 0 的學員
- **所需時間**：12 分鐘
- **學習重點**：
  - 理解模糊指令和具體指令的差異
  - 學會在指令中加入「誰、什麼、什麼時候、什麼條件」
  - 練習透過逐步加條件讓結果更精準
- **工具需求**：Claude Code，`~/horizon-academy/` 資料夾
- **本課產出**：本週英文班作業缺交統計表

---

## 🎬 拍攝腳本

### 場景 1：開場情境（30 秒）

**畫面：**
林老師打開 Claude Code，想整理作業繳交狀況，有點不知道從哪裡說起

**旁白：**
「林老師上完第一課，知道 Claude 很厲害，但今天遇到了第一個挑戰：她知道自己要什麼，但不知道要怎麼說才能讓 Claude 理解。這是很多人第一次用 AI 都會遇到的問題。」

**字幕：**
```
今天的任務：找出本週沒繳作業的學生
```

---

### 場景 2：第一次嘗試——模糊指令（45 秒）

**畫面：**
林老師輸入，Claude 回應並問了一堆問題

**使用者輸入：**
```
幫我整理一下作業的情況
```

**Claude 回應：**
```
我可以幫您整理作業情況！請問：
- 是哪個班級的作業？
- 是哪份作業？還是全部的？
- 您手邊有作業繳交的資料嗎？是什麼格式？
- 您想要什麼樣的整理結果？
```

**旁白：**
「Claude 問了四個問題。不是 Claude 不聰明——而是它需要更多資訊才能幫上忙。就像你叫助教『幫我整理一下』，好的助教也會問你到底要整理什麼。」

**字幕：**
```
💡 關鍵學習點：「幫我整理」太模糊了
AI 需要知道：誰、什麼、什麼時候
```

---

### 場景 3：什麼是好的具體指令？（40 秒）

**畫面：**
旁白解說，畫面顯示指令的拆解

**旁白：**
「讓我們來看看，一個好的指令應該包含什麼。想像你在給一位新助教工作說明——你不會說『幫我整理』，你會說：『請幫我整理第 3 班本週一到週五的作業繳交狀況，找出還沒繳的學生名字和缺交次數。』」

**字幕：**
```
好指令的四個元素：
✅ 誰：第 3 班的學生
✅ 什麼：英文週記作業的繳交情況
✅ 什麼時候：本週（週一到週五）
✅ 什麼條件：找出沒繳的人
```

---

### 場景 4：用具體指令再試一次（50 秒）

**畫面：**
林老師輸入完整指令（假設已有學生名單資料）

**使用者輸入：**
```
以下是第 3 班英文週記作業的繳交情況（日期是本週）：
[貼入學生名單和繳交打勾的表格]

請幫我：
1. 找出本週完全沒繳的學生姓名
2. 統計每位學生缺交次數
3. 用表格格式整理結果
```

**Claude 回應（示意）：**
```
根據您提供的資料，第 3 班本週作業繳交情況如下：

| 姓名 | 缺交次數 | 缺交日期 |
|------|---------|---------|
| 王小明 | 3 次 | 週一、週三、週五 |
| 陳美玲 | 1 次 | 週三 |
...

共 5 位同學本週有缺交情況。
```

**旁白：**
「看到差別了嗎？同樣是整理作業，具體的指令讓 Claude 一次就做出你想要的結果，不需要來回問答。」

---

### 場景 5：進階——加入條件讓結果更精準（40 秒）

**畫面：**
林老師繼續優化指令

**使用者輸入：**
```
在這個表格中，缺交超過 2 次的學生姓名旁邊加上 ⚠️，
並在表格最後加一個備注欄，說明建議的追蹤行動（例如：需要家長聯絡）
```

**旁白：**
「你不需要一次說完所有條件。可以先拿到第一個結果，再繼續加條件。這是跟 AI 協作的自然節奏——就像跟人討論一樣，一步一步推進。」

**字幕：**
```
💡 進階技巧：
先拿到基本結果，再逐步加條件
每次對話都在原本的基礎上改進
```

---

### 場景 6：總結（30 秒）

**畫面：**
完成的作業缺交統計表

**旁白：**
「今天林老師學到了指令的三個核心原則：說清楚對象、說清楚時間、說清楚條件。這個習慣，會讓你以後用 AI 的每次體驗都更流暢。」

**字幕依序顯示：**
```
✅ 說清楚誰（對象）
✅ 說清楚什麼（任務）
✅ 說清楚什麼時候（時間範圍）
✅ 說清楚什麼條件（篩選標準）
```

## 💡 延伸練習

### 練習 1：改寫模糊指令
以下是幾個模糊指令，試試把它們改成具體指令：
- 「幫我整理學生資料」
- 「寫一封家長通知信」
- 「分析成績」

### 練習 2：你的真實任務
想一個你這週實際需要完成的行政工作，試著用「誰、什麼、什麼時候、什麼條件」的框架描述給 Claude。

### 練習 3：比較結果
用模糊指令和具體指令各試一次同樣的任務，截圖比較兩個結果的差異。

## 📖 常見問題

### Q：我不確定需要說多具體，怎麼判斷？
A：一個簡單的測試：如果把你的指令給一位新助教，他需要問幾個問題才能開始做？問的問題越少，指令就越清楚。目標是「助教可以直接開始做」的程度。

### Q：指令可以很長嗎？
A：可以！對複雜任務，長指令通常比短指令效果更好。不用擔心指令太長，Claude 可以處理很長的文字輸入。

### Q：如果我說不清楚，Claude 會問我嗎？
A：通常會！Claude 在不確定的時候會問問題。但如果你養成給清楚指令的習慣，就能減少來回溝通的次數，效率更高。
