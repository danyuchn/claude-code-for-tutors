# 課程 3-1：讀懂學生成績背後的故事

從一堆數字中，讓 AI 幫你交叉比對多份資料，發現肉眼看不到的學習問題。

## 課程資訊
- **適合對象**：完成 Module 2 的學員
- **所需時間**：15 分鐘
- **學習重點**：
  - AI 可以同時讀取多份資料，進行交叉比對分析
  - AI 不只列數字，會主動提出「背後的故事」
  - 用口語描述擔心，AI 就能從數據中找到證據
  - 數字之間的關聯性，往往比單一指標更重要
- **工具需求**：Claude Code，`~/horizon-academy/` 資料夾
- **本課產出**：班級學習狀況報告（含每位學生的個別建議）

### 場景 1：開場情境（30 秒）

**畫面：**
林老師坐在辦公桌前，桌上攤開三份文件：月考成績單、出席記錄表、家長滿意度問卷。她打開 Claude Code。

**旁白：**
「學期過了一半，校長要求每位老師提交班級學習狀況分析報告。林老師手邊有三份資料——月考成績、出席記錄、家長問卷。分開看，每份都是一堆數字；要交叉比對找出問題，光想就頭痛。今天她決定讓小艾來幫忙。」

**字幕：**
```
今天的任務：從三份資料找出需要關注的學生
林老師的煩惱：每份資料單獨看都看不出問題
```

林老師輸入指令，Claude 同時讀取三個檔案

**使用者輸入：**

幫我分析班上學生的學習狀況，我有成績、出席和家長問卷三份資料
```

**Claude 回應：**

我來幫你分析班級學習狀況，先讀取所有資料：

[Tool: Read] exam-scores.csv
[Tool: Read] attendance-records.csv
[Tool: Read] parent-survey.csv
```

**旁白：**
「注意看！林老師只說了一句話，小艾立刻理解她需要綜合分析，而且同時讀取三份資料——成績、出席記錄、家長問卷。不是一個一個讀，是三個一起讀！這就是 AI 的並行處理，自動判斷需要什麼資料，一次全部載入。」

**字幕：**
```
關鍵學習點：AI 同時讀取多份資料
一句口語 → 三份資料並行載入分析
```

### 場景 3：驚喜時刻——問題不是學力，是 pacing（90 秒）

**畫面：**
Claude 顯示分析結果，重點標示出一位學生的交叉比對發現

**Claude 回應：**
```
分析完成，以下是需要特別關注的學生：

需要關注的學生

| 學生 | 成績趨勢 | 出席狀況 | 家長回饋 | 風險程度 |
|------|---------|---------|---------|---------|
| 陳志明 | 72→65→58 | 最近三週遲到 8 次 | 希望多關注學習動機 | 高 |
| 王美玲 | 68→62→55 | 正常 | 希望增加練習量 | 中 |
| 李承翰 | 75→70→66 | 缺席 3 次 | 無特別意見 | 中 |

我發現了一個有趣的模式。

表面上看，陳志明的成績從 72 降到 58——感覺是學力下滑。
但我交叉比對了出席記錄，他最近三週遲到了 8 次，
每次都超過 20 分鐘。
而且家長問卷顯示「希望老師多關注他的學習動機」。

這不是知識問題，這是 pacing 問題——
他上課跟不上進度，不是因為不夠努力，
而是每天都錯過了前 20 分鐘的關鍵引導。

建議：先跟陳志明聊聊遲到的原因，
而不是加強課後輔導。
```

**旁白：**
「這就是驚喜的地方！林老師原本期待看到的是『誰退步了、退步多少分』這種成績分析。但小艾做了更深入的事——它交叉比對了三份完全不同的資料，發現陳志明的問題根本不在學力！他每天遲到 20 分鐘，錯過了關鍵引導，這才是成績下滑的真正原因。家長問卷也佐證了這個判斷。這種跨資料的綜合洞察，人工做可能要花一整個下午。」

**字幕：**
```
驚喜時刻：AI 不只列數字，還找出「背後的故事」
成績下滑 + 頻繁遲到 + 家長回饋 = 問題在 pacing，不在學力
```

### 場景 4：深入追問——生成個別建議（60 秒）

**畫面：**
林老師繼續追問，要求為每位需要關注的學生提出具體建議

**使用者輸入：**
```
幫我針對每位需要關注的學生，各給一個具體的行動建議
```

**Claude 回應：**
```
個別學生行動建議

1. 陳志明（高風險）
   問題核心：pacing 問題（非學力問題）
   建議行動：安排一次面談，了解遲到原因。
   如果是交通問題，考慮提供前 20 分鐘的重點筆記；
   如果是動機問題，嘗試讓他擔任小組長角色。
   追蹤指標：下月遲到次數是否減少

2. 王美玲（中風險）
   問題核心：練習量不足導致知識無法固化
   建議行動：每週多給 2 份練習卷，
   並在第三次月考前安排一次小考確認進度。
   追蹤指標：作業繳交率和下次月考成績

3. 李承翰（中風險）
   問題核心：出席不穩定影響學習連貫性
   建議行動：聯絡家長了解缺席原因，
   確認是否有健康或家庭因素。
   追蹤指標：出席率恢復到 90% 以上
```

**旁白：**
「小艾不只分析問題，還針對每位學生的不同狀況，給出了完全不同的建議——陳志明需要面談了解遲到原因，王美玲需要增加練習量，李承翰要聯絡家長。每個建議都有追蹤指標，讓老師知道改善的方向。」

## 延伸練習

### 練習 1：你的班級資料交叉分析
把你班上的成績、出席紀錄（或任何其他資料）一起丟給 AI，看看它能發現什麼你沒注意到的關聯性。

### 練習 2：追蹤指標設定
針對 AI 分析出的需要關注學生，請 AI 幫你設定追蹤指標和檢查時間點，建立持續追蹤機制。

### 練習 3：跨學期比較
如果有上學期的資料，讓 AI 比較兩學期的變化，看看哪些學生的狀況是持續惡化、哪些已經改善。

## 常見問題

### Q：我只有成績資料，沒有出席記錄，還能分析嗎？
A：當然可以！即使只有成績，AI 也能找出趨勢（進步/退步/穩定）。但如果你能多提供一份資料（出席、作業繳交、課堂表現），交叉比對的效果會好很多。

### Q：AI 分析的結果一定對嗎？
A：AI 的分析基於你提供的數據，它能發現模式和關聯，但最終的判斷還是要靠老師。例如，AI 看到「遲到 + 成績下滑」推測是 pacing 問題，但你可能知道那位學生其實是家裡出了事。AI 是你的分析助手，不是決策者。

### Q：資料需要很完整才能分析嗎？
A：不需要。有缺漏的資料，AI 會告訴你哪些地方資料不足，並基於現有資料做最好的分析。不完美的資料總比不分析好。
