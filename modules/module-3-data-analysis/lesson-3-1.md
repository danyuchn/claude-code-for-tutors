# 課程 3-1：讀懂學生成績背後的故事

從一堆數字中，讓 Claude 幫你找出需要關注的學生和學習趨勢。

## 📋 課程資訊
- **適合對象**：完成 Module 2 的學員
- **所需時間**：18 分鐘
- **學習重點**：
  - 學會讓 AI 分析 CSV 成績資料找出趨勢
  - 了解如何從數字找出需要關注的學生
  - 生成可直接提交的班級學習狀況報告
- **工具需求**：Claude Code，`exam-scores.csv`
- **本課產出**：班級學習狀況報告（含需要追蹤的學生名單）
- **教師獨有場景**：✅ 是

---

## 🎬 拍攝腳本（骨架）

### 場景 1：陳老師的困境（25 秒）
> 介紹陳老師（數學老師），校長要求每位老師提交班級學習分析報告
> 他有一份 Excel，但看著數字不知道要說什麼故事

### 場景 2：讀取成績資料（30 秒）
> 讓 Claude 讀取 exam-scores.csv
> Claude 先確認資料結構和筆數

### 場景 3：基本分析（45 秒）

**關鍵指令範例：**
```
請分析這份三次月考成績資料（30 位學生）：

1. 基本統計
   - 三次月考的全班平均分
   - 最高分和最低分
   - 標準差（告訴我學生程度差距）

2. 趨勢分析
   - 全班平均分的趨勢（進步/退步/穩定）
   - 進步最顯著的前 3 位學生（進步幅度最大）
   - 退步最明顯、需要關注的 3 位學生

3. 需要追蹤的學生（重點！）
   - 三次都低於 60 分的學生名單
   - 出席率低於 80% 的學生
   - 出席率和成績有關聯嗎？

請用表格呈現結果，條理清晰
```

### 場景 4：生成給校長的報告（30 秒）
> 「請把分析結果整理成一份 300 字的班級學習狀況報告，適合呈給校長」

### 場景 5：下一步行動建議（20 秒）
> 「根據分析，建議我下學期的 3 個教學調整方向」

---

## 💡 延伸練習

### 練習 1：你的班級成績
把你班上的成績資料（可以匿名化）讓 Claude 分析，找出需要關注的學生。

### 練習 2：跨學期比較
如果有上學期的成績，讓 Claude 比較兩學期的變化趨勢。

### 練習 3：個人報告
為需要關注的學生各生成一份簡短的個人學習摘要，方便家長溝通用。

---

## 🎯 學習目標檢查

完成這一課後，你應該能夠：
- [ ] 讓 Claude 從 CSV 數據中找出統計趨勢
- [ ] 識別需要追蹤的學生（低分、缺席、退步）
- [ ] 生成可以提交給主管的分析報告
