# 課程 3-4：招生數據分析，讓行銷更精準

用數據找出最有效的招生管道，把資源投在對的地方。

## 📋 課程資訊
- **適合對象**：完成課程 3-3 的學員
- **所需時間**：15 分鐘
- **學習重點**：
  - 學會分析多維度的招生數據（管道、費用、轉換速度）
  - 從數字找出有意義的行動洞察
  - 生成可以直接使用的行銷建議報告
- **工具需求**：Claude Code
- **本課產出**：招生管道分析報告 + 下季行銷建議
- **教師獨有場景**：否（補教業通用）

---

## 🎬 拍攝腳本（骨架）

### 場景 1：張老師的招生困境（20 秒）
> 介紹張老師（升學諮詢），學校用了四個招生管道，但不確定哪個最划算
> 每個管道都在花錢，但效果差異很大

### 場景 2：輸入招生數據（35 秒）

**關鍵指令範例：**
```
以下是明日學院過去三個月的招生數據，請幫我分析：

管道資料：
- Instagram 廣告：帶來 15 位新生，平均諮詢到報名 12 天，花費約 NT$48,000
- 家長介紹（口碑）：帶來 18 位新生，平均諮詢到報名 5 天，花費 NT$0
- Google 搜尋廣告：帶來 8 位新生，平均諮詢到報名 20 天，花費 NT$44,000
- 社區傳單：帶來 4 位新生，平均諮詢到報名 8 天，花費 NT$4,800

分析問題：
1. 每個管道的「每人招生成本」是多少？
2. 轉換速度最快的管道是哪個？
3. 整體 CP 值最高的管道排名
4. 家長介紹雖然免費，但如何可以主動增加？
```

### 場景 3：深度分析（30 秒）
> 讓 Claude 生成視覺化的比較表格

### 場景 4：下季行動建議（25 秒）
> 「根據這個分析，建議下一季的行銷預算分配比例，並給出具體理由」

---

## 💡 延伸練習

### 練習 1：加入時間維度
如果有多個月份的數據，分析各管道的趨勢（哪個管道越來越好 / 越來越差）。

### 練習 2：學生留存分析
哪個管道帶來的學生留存率最高？（如果有續班資料）

---

## 🎯 學習目標檢查

完成這一課後，你應該能夠：
- [ ] 計算各招生管道的 CP 值（每人成本）
- [ ] 從多個維度比較管道效果
- [ ] 生成有數據支撐的行銷建議報告
