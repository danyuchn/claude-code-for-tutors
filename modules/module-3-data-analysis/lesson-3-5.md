# 課程 3-5：用截圖讓 AI 看懂你的問題

遇到視覺問題，截圖比描述有效 10 倍——而且 AI 能看到你沒注意到的細節。

## 課程資訊
- **適合對象**：完成課程 3-4 的學員
- **所需時間**：12 分鐘
- **學習重點**：
  - 截圖是與 AI 溝通視覺問題的最佳方式
  - AI 不只回答你問的，還會主動發現你沒注意到的問題
  - 學會判斷什麼時候用截圖、什麼時候用文字
  - 截圖的「最佳實踐」——截什麼、怎麼截
- **工具需求**：Claude Code，截圖工具（Mac：Cmd+Shift+4）
- **本課產出**：問題診斷報告 + 截圖溝通最佳實踐指南

## 拍攝腳本

陳老師（數學老師）在 Excel 前面皺眉，螢幕上可以看到一個成績表，有些格子顯示不正常。他打開 Claude Code。

**旁白：**

**字幕：**
```
今天的任務：讓 AI 從截圖中找出試算表的問題
陳老師的困境：看著數字覺得怪，但說不出哪裡不對
```

### 場景 2：文字描述的限制（40 秒）

**畫面：**
陳老師先嘗試用文字描述問題

**使用者輸入：**
```
我的成績試算表好像有問題，有些平均分算出來不太對
```

**Claude 回應：**
```
我需要更多資訊才能幫你診斷：
- 是哪一列或哪一行的平均分有問題？
- 你覺得正確的數值應該是多少？
- 平均分的公式是什麼？
- 有沒有空白的儲存格？
- 是 Excel 還是 Google 試算表？
```

**旁白：**
「看到了嗎？用文字描述試算表的問題，AI 需要問很多細節才能幫上忙。陳老師可能得來來回回好幾次。但如果用截圖呢？」

**字幕：**
```
文字描述 → AI 需要問 5 個問題才能開始幫忙
截圖 → AI 一看就懂
```

### 場景 4：驚喜時刻——AI 看到兩個老師沒發現的問題（90 秒）

**畫面：**
陳老師把成績表截圖貼給 Claude，Claude 找出兩個問題

**使用者輸入：**
```
這份成績表哪裡有問題？
[貼入截圖]
```

**Claude 回應：**
```
我從截圖中看到了這份期末成績表。
讓我仔細檢查......我發現了兩個問題：

問題 1：公式錯誤（S018 趙俊傑）

S018 趙俊傑的平均分公式是 =SUM(C18:E18)/3，
但 E18 是空的——第三次月考沒有成績。

這表示平均分的計算是偏低的：
- 目前計算：(75 + 68 + 0) / 3 = 47.7
- 正確計算：(75 + 68) / 2 = 71.5

你需要確認他是否確實沒有參加第三次月考，
還是資料遺漏。如果是前者，公式應該改成
=AVERAGE(C18:E18)，它會自動忽略空值。

問題 2：可疑的等差數列（S023 林美華）

S023 林美華的三次月考成績是 38、39、40——
每次剛好差一分，形成完美的等差數列。

這在真實考試中非常不自然。
可能是資料輸入錯誤？
或是不小心用了自動填充功能？

建議：核對一下 S023 的原始考卷分數。

其他部分看起來都是正常分布，沒有異常。
```

**旁白：**
「這就是驚喜的地方！陳老師只說了『哪裡有問題？』，沒有說什麼問題。但小艾從截圖裡找到了兩個老師自己都沒發現的問題！第一個是公式錯誤——趙俊傑的平均分因為空值被算成 47 分，實際應該是 71 分，差了將近 24 分。第二個更細微——林美華三次考 38、39、40，這種完美的等差數列在真實考試中幾乎不可能出現，可能是輸入錯誤。這兩個問題，光看數字很難發現，但 AI 一眼就看到了。」

**字幕：**
```
驚喜時刻：老師沒說什麼問題，AI 自己找到兩個
問題 1：公式錯誤讓 71 分被算成 47 分
問題 2：38、39、40 等差數列太不自然
```

### 場景 5：什麼時候用截圖、什麼時候用文字（45 秒）

**畫面：**
整理出一個對照表

**旁白：**
「經過前面的體驗，我們來整理一下：什麼時候適合用截圖，什麼時候適合用文字描述。」

**Claude 回應：**
```
截圖 vs 文字描述 選擇指南

適合用截圖的情境：
- 試算表出現公式錯誤或數值異常
- 排版跑掉（Word、PPT、網頁）
- 看到錯誤訊息但不懂什麼意思
- 介面操作不知道按哪個按鈕
- 任何「我看到了但說不清楚」的問題

適合用文字描述的情境：
- 問題是邏輯性的（「怎麼分組比較好？」）
- 需要生成內容（「幫我寫一封信」）
- 資料分析（直接給 CSV 比截圖好）
- 問題可以用一句話說清楚

截圖的最佳實踐：
1. 只截有問題的部分，不要截整個螢幕
2. 確保截圖清楚，文字可以辨識
3. 搭配一句簡短描述（「這裡哪裡有問題？」）
4. 如果問題在多個地方，可以截多張
```

**旁白：**
「簡單的判斷原則：如果你覺得『用說的很難說清楚』，那就截圖。如果問題可以用一句話說清楚，那就用文字。」

## 延伸練習

### 練習 1：截圖診斷挑戰
找一個你電腦上的「看不懂的東西」截圖貼給 AI 診斷。可以是試算表、文件排版、或任何軟體介面。

### 練習 2：學習截圖技巧
練習只截取最相關的區域（不要截整個螢幕），讓 AI 更快找到問題所在。嘗試在截圖旁加上簡短的文字描述。

### 練習 3：比較文字 vs 截圖
選一個問題，先用文字描述讓 AI 回答，再用截圖讓 AI 回答，比較兩種方式的效率和準確度。

## 常見問題

### Q：截圖裡有學生的個人資料，可以給 AI 嗎？
A：Claude Code 的對話不會被用來訓練模型，但如果你擔心，可以先把姓名等個資遮掉再截圖。重點是讓 AI 看到數字結構和格式，不一定需要看到具體的姓名。

### Q：我用的是 Google 試算表，截圖可以嗎？
A：可以！不管是 Excel、Google 試算表、Numbers、甚至手寫的表格拍照，AI 都能辨識和分析。

### Q：如果截圖太模糊，AI 看不清楚怎麼辦？
A：AI 會告訴你哪裡看不清楚，並請你重新截取。建議放大到 100% 以上再截圖，確保文字清晰。
