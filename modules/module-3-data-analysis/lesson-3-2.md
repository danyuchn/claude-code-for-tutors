# 課程 3-2：從家長滿意度調查找改進方向

用 AI 分析問卷，找出量化數據和質性意見中的改進重點。

## 📋 課程資訊
- **適合對象**：完成課程 3-1 的學員
- **所需時間**：15 分鐘
- **學習重點**：
  - 學會分析混合型問卷（量化評分 + 質性文字）
  - 讓 AI 從開放式意見中找出主要主題
  - 生成有行動建議的分析報告
- **工具需求**：Claude Code，`parent-survey.csv`
- **本課產出**：問卷分析摘要 + 下學期改進行動清單
- **教師獨有場景**：✅ 是

---

## 🎬 拍攝腳本（骨架）

### 場景 1：問卷分析的挑戰（20 秒）
> 林老師收到 20 份家長問卷回覆，有評分也有文字意見
> 一條一條讀完很費時，且很難看出重點

### 場景 2：量化分析（35 秒）

**關鍵指令範例：**
```
請分析 parent-survey.csv 的家長滿意度問卷：

量化部分：
- 三個面向（整體滿意度、教學品質、溝通效率）的平均分
- 哪個面向分數最高？哪個最低？
- 分數分布：各有幾位家長給 5 分、4 分、3 分以下？
```

### 場景 3：質性分析（35 秒）
> 繼續讓 Claude 分析文字意見

**關鍵指令範例（接續上一步）：**
```
接著分析開放式文字意見：
- 找出家長最常提到的「正面評價」（前 3 個主題）
- 找出家長最常提到的「改進建議」（前 3 個主題）
- 有沒有特別具體、值得重視的個別意見？
```

### 場景 4：行動建議（25 秒）
> 「根據以上分析，給我 3 個可以在下學期立即改善的具體行動，按優先順序排列」

---

## 💡 延伸練習

### 練習 1：分析你的問卷
如果你有收過任何形式的回饋（家長意見、學生課堂回饋），讓 Claude 幫你分析。

### 練習 2：設計更好的問卷
讓 Claude 根據這次分析的發現，建議如何改善問卷設計，讓下次收到更有用的回饋。
