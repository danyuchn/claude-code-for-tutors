# 課程 3-3：追蹤學生進度，一目瞭然

建立可重複使用的學生進度查詢系統，家長問什麼都能秒回。

## 📋 課程資訊
- **適合對象**：完成課程 3-2 的學員
- **所需時間**：15 分鐘
- **學習重點**：
  - 學會建立可重複使用的查詢模板
  - 讓 AI 整合多個資料來源提供全面摘要
  - 了解如何讓查詢系統對特定條件做批次查詢
- **工具需求**：Claude Code，`student-roster.csv`，`exam-scores.csv`
- **本課產出**：學生進度查詢模板（輸入學號即顯示完整摘要）
- **教師獨有場景**：✅ 是

---

## 🎬 拍攝腳本（骨架）

### 場景 1：家長電話的困境（20 秒）
> 家長打電話問「我孩子英文怎麼樣」
> 林老師要翻好幾個地方才能找到完整資訊，家長在電話上等著很尷尬

### 場景 2：設計查詢系統（40 秒）

**關鍵指令範例：**
```
請幫我建立一個學生進度查詢系統。
當我輸入學號，請從以下資料整合顯示完整摘要：
- student-roster.csv（基本資料）
- exam-scores.csv（成績記錄）

顯示格式：
📋 學生基本資料
- 姓名：
- 年級：
- 出席率：

📊 成績概況
- 三次月考：X 分 → X 分 → X 分
- 趨勢：（進步 / 退步 / 穩定）
- 作業繳交率：

⚠️ 需要注意的事項
（如果有出席率低於80%或成績持續下滑，在這裡提示）

💡 建議行動
（根據學生狀況的一句話建議）

請先查詢學號 S001 測試這個格式
```

### 場景 3：測試查詢（25 秒）
> 輸入不同學號，展示查詢結果
> 強調：這個指令可以重複使用

### 場景 4：批次查詢（20 秒）
> 「幫我查詢出席率低於 80% 的所有學生，列出名單和建議行動」

---

## 💡 延伸練習

### 練習 1：自訂顯示格式
根據你的需要，調整查詢結果的顯示格式（加入你最常需要的資訊）。

### 練習 2：批次查詢應用
讓 Claude 幫你找出「需要主動聯絡家長的學生」（根據你設定的條件）。

---

## 🎯 學習目標檢查

完成這一課後，你應該能夠：
- [ ] 建立整合多個資料來源的查詢模板
- [ ] 用學號快速查詢學生完整摘要
- [ ] 用條件篩選批次找出需要關注的學生
