# 課程 3-3：追蹤學生進度，一目瞭然

把老師的「直覺」變成「數據」——當你覺得某個學生不對勁，AI 幫你找到具體證據。

## 課程資訊
- **適合對象**：完成課程 3-2 的學員
- **所需時間**：15 分鐘
- **學習重點**：
  - AI 可以把模糊的「感覺」轉成具體的數據趨勢
  - 多個指標同步變化比單一指標更有意義
  - AI 會主動判斷「這是突然事件還是持續惡化」
  - 建立可重複使用的學生進度查詢流程
- **工具需求**：Claude Code，`~/horizon-academy/` 資料夾
- **本課產出**：進度追蹤儀表板模板

---

## 拍攝腳本

### 場景 1：開場情境（30 秒）

**畫面：**
林老師在改作業時停下來，若有所思地看著某位學生的考卷。她拿起手機想打電話給家長，但又猶豫了——因為她說不出具體哪裡不對。她打開 Claude Code。

**旁白：**
「身為老師，你一定有過這種直覺——覺得某個學生最近『怪怪的』，但又說不出具體哪裡不對。你想跟家長聊聊，但沒有數據支撐，只憑感覺又不太好說。今天我們要學的就是：怎麼讓 AI 把你的直覺變成數據。」

**字幕：**
```
今天的任務：把「感覺不對勁」變成具體的數據
林老師的困境：直覺某學生有問題，但說不出具體證據
```

---

### 場景 2：用模糊的方式提問——AI 精準定位（60 秒）

**畫面：**
林老師用很口語、很模糊的方式描述她的擔心

**使用者輸入：**
```
幫我看看林志豪最近的狀況，感覺他有點不對勁
```

**Claude 回應：**
```
[Tool: Read] student-roster.csv

搜尋中......找到了。
林志豪，高一英文班，學號 S047。

讓我查看他的完整資料：

[Tool: Read] exam-scores.csv
[Tool: Read] attendance-records.csv
```

**旁白：**
「注意林老師怎麼說的——『感覺他有點不對勁』。沒有說要查什麼資料，沒有指定分析方法。小艾立刻理解了：先定位這個學生是誰，然後去撈他的成績和出席資料。」

---

### 場景 3：驚喜時刻——三個指標同步下滑（90 秒）

**畫面：**
Claude 顯示完整的趨勢分析，重點標示出三個同步下滑的指標

**Claude 回應：**
```
林志豪 S047 — 最近三個月趨勢分析

成績趨勢：
月考成績：78 → 71 → 64（每月下降約 7 分）

作業繳交：
第一個月：全部繳交（100%）
第二個月：缺繳 2 次（80%）
第三個月：缺繳 5 次（50%）

出席率：
95% → 88% → 80%

三個指標同步下滑趨勢圖：
第一月  ████████████████████  78分 | 100%繳交 | 95%出席
第二月  ██████████████████    71分 |  80%繳交 | 88%出席
第三月  ████████████████      64分 |  50%繳交 | 80%出席

判斷：
三個指標同步下滑，而且是漸進式的——
不是突然某一次考砸了，而是持續、穩定地惡化。
這代表不是突發事件（像是某次考前生病），
而是某個持續存在的壓力源在影響他。

建議：
主動跟林志豪約談，先問他最近的狀況，
再談學習。重點不在分數，在了解發生了什麼事。
```

**旁白：**
「這就是驚喜的地方！林老師只說了一句『感覺不對勁』，小艾做的事是——把三個不同的指標放在一起看：成績、作業、出席，三個全部同步下滑。而且小艾做了一個很重要的判斷：這不是突發事件，而是持續壓力源。因為如果只是某次考前生病，應該只有那次考試受影響，但林志豪是連續三個月穩定惡化。這就是把『感覺』轉成『數據支撐』。」

**字幕：**
```
驚喜時刻：「感覺不對勁」→ 三個指標同步下滑
AI 的判斷：漸進式惡化 = 持續壓力源，不是單次事件
```

### 場景 4：建立可重複使用的查詢——儀表板模板（60 秒）

**畫面：**
林老師決定建立一個方便查詢任何學生的模板

**使用者輸入：**
```
這個方式很好用！可以幫我做一個模板，以後我輸入任何學生的名字，都可以快速看到這種趨勢分析嗎？
```

**Claude 回應：**
```
好的，我來建立一個學生進度查詢模板。

[Tool: Write] student-progress-template.md

模板已建立！以後你只要跟我說：

「查一下 [學生姓名] 的狀況」

我就會自動顯示：
  1. 基本資料（姓名、學號、班級）
  2. 成績趨勢（三次月考走勢 + 判斷）
  3. 出席狀況（出席率 + 遲到次數）
  4. 作業繳交率
  5. 需要注意的警示（如果有的話）
  6. 建議行動

要不要現在測試一下？
試試說：「查一下王美玲的狀況」
```

**旁白：**
「小艾幫林老師建立了一個模板，以後只要說『查一下某某的狀況』，就能快速看到完整的趨勢分析。這就像有一個隨時待命的助教——家長打電話來問孩子的狀況，你幾秒鐘就能調出完整的資料。」

|------|------|---------|--------|

| 陳志明 | 72→65→58 | -14 分 | 高 |

| 學生 | 出席率 | 遲到次數 | 優先級 |

## 延伸練習

### 練習 1：查詢你關心的學生
想一個你最近覺得「不太對勁」的學生，用最自然的方式跟 AI 描述，看看數據能告訴你什麼。

### 練習 2：設定預警條件
讓 AI 幫你設定「自動預警條件」——例如「成績下滑超過 10 分」或「連續缺席 3 次」，定期篩選出需要關注的學生。

### 練習 3：建立個人儀表板
根據你最常需要的資訊，客製化你的學生進度查詢模板。

## 常見問題

### Q：我的學校沒有數位化的出席記錄，怎麼辦？
A：你可以手動把重要的資訊輸入——不需要完整資料，即使只有成績和你的觀察筆記，AI 也能幫你分析趨勢。

### Q：AI 說「持續壓力源」，但我不知道是什麼，怎麼辦？
A：AI 能告訴你「有問題」和「問題的模式」，但原因還是需要你去了解。建議先跟學生談談，再結合 AI 的數據分析，通常就能找到答案。
