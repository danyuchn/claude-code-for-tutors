# 課程 0-1：為什麼老師需要 AI 助理？

了解 AI 如何幫助教師從繁瑣行政中解放出來。

## 📋 課程資訊
- **適合對象**：完全新手，從未使用過 AI 工具
- **所需時間**：10 分鐘
- **學習重點**：
  - 認識教師日常工作中哪些任務可以 AI 輔助
  - 了解 Claude Code 與一般 AI 聊天的差別
  - 建立「AI 是助理，不是替代者」的正確心態
- **工具需求**：無（純觀念課）
- **本課產出**：無檔案，但學員應能說出 3 個 AI 可以幫自己的場景

## 🎬 拍攝腳本

### 場景 1：開場——林欣怡老師的一天（90 秒）

**畫面：**
快速剪輯林老師的一天：早上批改作業、中午回覆家長 LINE、下午上課、晚上統計成績、深夜寫社群貼文。最後定格在時鐘顯示「晚上 11:30」。

**旁白：**
「這是林欣怡老師的一天。她是明日學院的英文老師，有 8 年教齡、120 位學生。她熱愛教學，但每週有超過 15 小時花在行政工作上——批改、統計、回覆、發文……這些事情必要，但不是她最想做的事。」

**字幕：**
```
林欣怡老師
英文老師，8 年教齡
每週行政工作：15+ 小時
```

---

### 場景 2：三個最痛的工作（60 秒）

**畫面：**
三個分割畫面，每個畫面對應一個痛點

**旁白：**
「讓我們看看三個最耗時的工作。第一，每學期期末要手動彙整 120 份學生成績，平均花 4 小時。第二，每週回覆 20-30 封相似的家長訊息，每封要花 5-10 分鐘思考措詞。第三，學校要求定期發社群貼文，但靈感不來的時候，一篇貼文可以讓她盯著螢幕一個小時。」

**字幕：**
```
成績彙整：4 小時/學期末
家長回覆：2-3 小時/週
社群貼文：1 小時/篇（靈感枯竭時）
```

---

### 場景 3：AI 能做什麼？（60 秒）

**畫面：**
同樣三個場景，但這次加上 Claude Code 的畫面——AI 快速完成

**旁白：**
「如果有一個助理，能幫你做成績彙整，只需要 10 分鐘？如果可以輸入幾個關鍵字，自動生成 20 封個人化的家長回覆？如果只要說出課程特色，就能生成有溫度的社群貼文？這不是科幻小說，這是今天的課程要教你的事。」

**字幕：**
```
成績彙整：4 小時 → 10 分鐘
家長回覆：批次生成，各不相同
社群貼文：有個人風格，不是 AI 味
```

---

### 場景 4：Claude Code 跟 ChatGPT 的差別（45 秒）

**畫面：**
兩個聊天視窗對比

**旁白：**
「很多老師用過 ChatGPT，覺得 Claude Code 只是另一個聊天機器人。但有個關鍵差別：Claude Code 可以直接操作你的電腦——讀取你的 Excel 檔案、整理你的資料夾、幫你建立新文件。就像差別在於：一個是可以幫你想主意的朋友，另一個是可以幫你實際做事的助理。」

**字幕：**
```
一般 AI 聊天：「可以幫你想」
Claude Code：「可以幫你做」
```

## 📖 常見問題

### Q：AI 會不會取代老師的工作？
A：AI 最擅長處理重複性、結構化的工作（統計、格式化、批次生成）。「理解學生、建立關係、激發學習動機」這些核心教師工作，目前 AI 無法替代。AI 是讓你把時間花在更有意義的事上的工具。

### Q：使用 AI 生成的內容，算不算欺騙？
A：這要看使用情境。用 AI 草稿、老師審閱修改後發出的家長通知信，是工具的使用。但完全不看就發出，可能有問題。本課程強調的是「AI 助手、老師把關」的模式。

### Q：這個課程要花多少時間？
A：完整課程約 5-7 小時，可以分多次上。每一課都獨立，也可以只上你最需要的部分。
