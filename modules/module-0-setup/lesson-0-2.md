# 課程 0-2：安裝與第一句話

陪林欣怡老師完成安裝，建立教學工作基地，說出第一句 AI 指令。

## 📋 課程資訊
- **適合對象**：完全新手
- **所需時間**：20 分鐘
- **學習重點**：
  - 在終端機（Terminal）安裝 Claude Code
  - 建立 `~/horizon-academy/` 工作資料夾
  - 完成第一次完整的工作任務對話
- **工具需求**：Mac 或 Windows 電腦，網路連線
- **本課產出**：`~/horizon-academy/` 資料夾 + 第一次對話記錄

---

**畫面：**

**旁白：**
「林老師決定要試試看了。今天要安裝 Claude Code，這個步驟可能是整個課程最技術的部分——但也只有這一次。之後的所有操作，都只是打字說話而已。」

**字幕：**
```
今天要做的事：
1. 安裝 Claude Code（只需要一次）
2. 建立工作基地
3. 說出第一句話
```

### 場景 2：打開終端機（45 秒）

**畫面：**
在 Mac 上用 Spotlight 搜尋「Terminal」並打開

**旁白：**
「首先要打開終端機（Terminal）。在 Mac 上，按 Command + 空白鍵，打入 Terminal，按 Enter。第一次看到這個黑色的視窗，很多人會緊張——沒關係，這是正常反應。想像它是一個可以接收文字指令的視窗，我們就是要在這裡安裝 Claude Code。」

**使用者輸入（終端機）：**
```bash

node --version
```

**畫面：**
如果有版本號出現（如 v20.x.x），繼續下一步
如果出現錯誤，提示去 nodejs.org 安裝

### 場景 3：安裝 Claude Code（60 秒）

**畫面：**
在終端機輸入安裝指令，等待安裝完成

**旁白：**
「一行指令就能安裝完成。這個指令的意思是：『幫我從網路上下載並安裝 Claude Code』。」

**使用者輸入：**
```bash

```

**畫面：**
看到進度條和安裝過程

**旁白：**
「安裝需要 1-2 分鐘，這時候可以去倒杯水。」

**安裝完成後：**
```bash

```

**字幕：**
```

```

### 場景 6：第一句話（60 秒）

**畫面：**
林老師深呼吸，然後打字

**旁白：**
「現在，林老師要說她人生第一句 AI 指令。不需要特殊語法，就說你最自然的需求。」

**使用者輸入：**
```
你好，我是明日學院的英文老師林欣怡，我想用你來幫我管理學生資料。
我有 120 位學生，每學期都要花很多時間在行政工作上。

```

**Claude 回應（示意）：**
```

我可以幫您：
- 整理和分析學生成績資料
- 批次生成個人化的家長通知信
- 搜尋和整理教學材料

```

**旁白：**
「Claude 用友善的方式回應，並主動詢問想從哪裡開始。這就是跟 AI 協作的感覺——就像有一個隨時可以問話的助手。」

## 📖 常見問題

### Q：我用 Windows，安裝步驟一樣嗎？
A：大致相同，但需要先安裝 WSL（Windows Subsystem for Linux）。安裝步驟請參考官方文件，或直接問 Claude：「我用 Windows 要怎麼安裝你？」

### Q：安裝時出現錯誤怎麼辦？
A：最常見的原因是 Node.js 版本太舊。先執行 `node --version` 確認版本，建議使用 v18 以上。如果還是有問題，把錯誤訊息截圖，我們下一課學習怎麼讓 AI 幫你診斷錯誤！

### Q：claude 這個指令可以在任何資料夾用嗎？
A：可以！`claude` 是全域安裝的指令，在任何目錄都能啟動。但建議在 `~/horizon-academy/` 工作時，先 `cd ~/horizon-academy` 再啟動，這樣 Claude 就能存取這個資料夾裡的所有檔案。

### Q：需要付費嗎？
A：Claude Code 需要 Anthropic 帳號，有免費額度，超過後需要付費。請參考官方網站的最新方案。
